# PPT 内容、页面与逐字稿

围绕听众需要获得的认识组织整场讲述，让页面承载材料与证据，让讲稿完成解释，交付能够展示、讲述和继续编辑的成果。

## 确定本次任务

从当前请求和已有材料中确定听众、用途、时长、重点及交付形式；分别识别**内容基准、样式基准、修改范围**。三者可以来自不同文件，以用户最新指定的版本为准。

用户当前明确要求优先于本 skill 的默认做法；未被改变的项目约定继续有效。已有信息足够时直接执行，只询问会改变讲述方向或修改对象、且无法从材料确定的信息。制作、修改已获授权时，继续完成相应文件及检查；只讨论方案时交付方案。

新建 PPT 默认使用 **学术蓝模板**，用户明确指定的其他模板或样式优先。修改既有 PPT 时保留其已确认样式，除非本次要求更换模板；仅处理逐字稿或备注时不调整页面样式。

## 从当前阶段推进

### 新建或重构

先明确整场核心问题和拟给出的回答，再安排各部分职责及关系，随后组织连续页组，最后确定页面文字、图表和口播。每项主要材料都应有可说明的作用；用它增加的认识决定保留、合并或删去。

分配各部分时间，再按解释难度安排页组篇幅。页数、图文比例和逐页时长服从本次内容与时间要求。把“本页观点”“讲解任务”等设计说明转为面向听众的标题与表达。

生成前按[检查内容方案](references/content-design.md#检查内容方案)核对大纲，修正发现的内容与结构问题后再制作；用户只要求方案时，在该阶段交付。

### 既有 PPT 配稿

先通读标题、正文、图表和现有备注，按章节或连续页组起草，再对应实际页码。根据本节职责确定背景、读图和机制解释的深度。

只授权写稿时，把可补充的解释写进讲稿；需要改变页面或页序才能解决的问题，给出具体修改建议。已授权同步调整 PPT 时直接处理。

### 局部修改

读取目标对象的当前内容及必要上下文，判断反馈改变的是结构、解释深度、措辞、版式还是交付格式，在对应层级修订。在允许修改的范围内处理同类问题；核对前后承接及仍有效的格式约定。

## 页面正文与讲稿

| 载体 | 主要职责 |
| --- | --- |
| 页面正文与图表 | 用正式、客观、简洁、适合公开展示的书面表达，呈现研究对象、关键关系、读图条件和支持判断的材料 |
| 演讲者备注 | 提供可以直接讲出口的解释与过渡 |
| 页面页脚 | 按需标明文献来源、页码或用户要求的版权信息 |
| 图注与技术标注 | 在图表附近标明变量、单位、图例及影响当前结果解读的条件 |
| 独立讲稿与备课资料 | 按任务保留补充讲述、完整出处、图表定位和查证信息 |

以下取舍规则适用于全部可见文字，包括正文、图内标注、脚注和技术注释。按文字对听众的实际用途判断，不因被归为“图注”或“技术说明”而豁免：

- **信息增量：** 每个正文文本框都应提供事实、概念、方法、证据、结果或必要的逻辑关系。删除仅有修辞作用的总结、过渡和解释；允许留白，不为填满版面补写文字。
- **正文与口播分离：** 演讲者的口语化讲解、阅读提示、转场和补充说明不写入正文。确有讲述用途时移入逐字稿，否则删除；定义、图例和必要条件用简洁书面表达就地呈现。
- **删除防御性表达：** 事实核查、绘图检查和制作取舍在制作过程中完成。发现错误就修正内容，不把检查过程、制作意图、自我辩护、假想质疑及回应写进成品。仅用于自证严谨、预防质疑或解释图表没有表达什么的文字直接删除，不改写后保留，也不移入备注或逐字稿。
- **教学举例与示意：** 根据当前听众、标题和内容已经能识别为举例、类比或概念示意时，不默认添加“虚构”“仅供示意”“非实测”等声明，也不解释显而易见的箭头、连线或色块。若当前呈现确实会把模拟数据当成真实结果，或把一种关系画成另一种关系，先修正图形、标题或就地标签，不在页脚追加免责声明。
- **条件与局限：** 必要的方法条件、研究局限和不确定性必须在相关方法、结果或局限性页面准确表达；直接陈述具体条件及其影响，不在无关页面反复附加免责声明，也不把判断所必需的条件仅移入讲稿。
- **结论区域：** 不默认在每页底部添加总结句、启示句、Key Takeaway、总结条或结论框。仅当某页确有需要强调、由研究材料支持的独立研究结论时才使用结论区域；不重复标题或正文已有判断。
- **标题与结构：** 标题可采用主题、问题或有证据支持的结论，不强制结论式标题。要点数量、各部分页数和排版由内容决定，不强制每页三点或各部分采用相同结构。

判断说明文字是否必要，看删除后是否会造成对当前对象、变量、数据或结论的具体误读；不能仅以“可能有人质疑”为由保留。教学例句用连线展示上下文关系时，“虚构报告；连线表示信息联系，非实测注意力权重”直接删除，保留例句和关系示意。

保留来源、页码及确实影响理解的图例、单位和条件；不把模拟数值或教学场景写成真实研究结果。明确区分事实、作者观点、讲者解释和评价；具体数字、历史关系和强断言核对原始来源，详细溯源放在适合查证的位置。

## 制作与完成

本 skill 提供内容与表达要求。生成或编辑实际文件时，使用当前环境可用的演示文稿工具或文件处理能力，并遵循其格式与操作说明；按任务需要选择实现方式。

交付前检查用户实际会使用的结果：

- **内容方案：** 各部分职责、材料选择、前后关系与时间安排足以指导制作。
- **逐字稿：** 连续阅读主讲正文，核对前提、指代、术语、转场及指图位置；篇幅包含读图、演示、停顿所需时间。估时注明依据，只有实际试讲后才报告实测时长。
- **文件：** 按[修改与交付](references/revision-delivery.md)检查最终保存文件。新建 PPT 生成后逐页检查全部可见文字和布局；发现违反上述取舍规则或版面要求的内容，直接修改并复查后再交付。局部修改按受影响范围检查；涉及备注时，重新读取实际备注，并按[备注清理](references/speaker-notes.md#内嵌演讲者备注)逐页核对。

交付一个明确的正式入口，简要说明完成的内容、实际检查及影响使用的未完成项。缺少编辑、渲染或播放能力时，交付已经完成的部分并说明具体缺口，不把大纲、生成成功或静态预览称为完整成品。

# PPT 内容、页面与逐字稿

围绕听众需要建立的认识组织整场讲述，让页面用凝练标题、完整书面长句与清晰图表承载关键判断和依据，让逐字稿完成连续推演与衔接，交付可直接展示、讲述和继续编辑的文件。

## 明确任务与模板归属

从请求和已有材料中确定听众背景、汇报用途、时长、参考内容、样式来源和修改范围。信息足够时直接制作或修改文件，只询问确实无法从材料推断、又会改变讲述主线或修改对象的问题；只讨论方案时交付方案。

**内容逻辑与模板样式分离：**
- 用户提供了 PPT 模板、参考课件或指定视觉风格时，直接沿用该模板的母版、配色、字体、标题区位置和版式规范；修改既有 PPT 时保留其原有样式；只改逐字稿或备注时不改动页面版式。
- 用户未提供模板且未指定其他风格时，新建 PPT 默认采用[学术蓝默认模板](references/academic-blue-style.md)（具体色值、字体字号、标题下划线与卡片版式均在该模板文档中定义，不在通用流程中硬编码）。

## 按需读取参考文档

只读取与当前任务相关的参考文档；局部修订复用已确认的整体安排，补读受影响部分即可。

## PPT 制作逻辑与推进理解

### 1. 整体推进与任务分支

- **新建或重构**：先明确整场要回答的核心问题和主要判断，再划分各章节职责与前后逻辑关系，随后规划连续页组，最后落定每页文字、图表和口播。每页和每项材料都要推进听众理解，合并重复铺垫、删去偏离主线的旁支。页数、图文比例和时长分配服从内容需要与时间限制。先按[检查内容方案](references/content-design.md#检查内容方案)核对大纲再生成页面；只要求大纲时在此阶段交付。
- **既有 PPT 配稿**：通读全部页面标题、正文、图表和已有备注，按章节和连续页组起草讲稿，再对应具体页码。只写讲稿时，将补充解释放入讲稿，需要改动页面或页序的问题另列建议；同步改 PPT 时直接调整。
- **局部修改**：先看目标页及前后衔接，判断反馈指向结构、内容深度、措辞、图文排版还是备注，在对应层级修改，并同步处理同文件内的同类问题与前后承接。

### 2. 内容深度与理解链条

根据章节在整场中的职责决定展开深度，使听众沿“问题从何而来 → 核心概念与方法如何运作 → 数据支持什么判断 → 边界与后续方向是什么”连贯理解：

- **背景与动机**：交代具体应用场景、已有条件及尚未解决的核心矛盾，让听众明白问题为什么重要、后文要回答什么。
- **概念与定义**：给出直观例子、核心定义、判据和必要的边界情况，使听众能据此分辨新例子；前置概念先于依赖它的页面出现。
- **方法与机制**：写清任务条件、输入表示、关键操作步骤、中间产物与输出目标，使听众能够完整走通一轮推理或计算循环，不止于罗列模块名称。
- **结果与比较**：交代比较基准、实验条件、评价指标含义与关键观察，在同一维度下横向对比，让听众看清数据支持多大范围的结论。
- **讨论与总结**：回应开场提出的问题，归纳研究贡献、适用边界及尚待验证的问题。

人名、时间、方法名、具体数值和实验条件须核对原始材料，区分预印本与正式发表版本；缺少原始依据时如实收窄结论或标明待核对，不编造数据或出处。

## 展示文字写作风格与反防御要求

| 载体 | 主要职责与写作风格 |
| --- | --- |
| 页面标题 | 用凝练的一句话或“方面：核心概括/判断”点明本页主题或结论，与章节名分工明确、不重复同一句话 |
| 页面正文与表格说明 | 用正式、客观、能独立读懂的**完整书面长句**呈现核心判断、对象、条件、机制和结果 |
| 图注与技术标注 | 就近放在图表旁，简明标注变量、单位、图例和影响结果解读的必要条件 |
| 参考文献脚注 | **仅在必要时添加**：只在页面直接引用他人论文原图、原表、实验数据或核心观点且需注明出处时标注 |
| 演讲者备注 / 独立讲稿 | 备注放可直接朗读的自然口语解释与过渡；完整出处明细、图号定位和备查信息放入独立讲稿或备课资料 |

页面可见文字（含标题、正文、表格、图注和标注）统一遵循以下写作规范：

- **完整长句表述，留白优于凑字**：正文段落、分组说明与表格描述写成表意完整的句子（交代清楚研究对象、作用关系或约束条件），使听众不听口播也能从屏幕读懂核心逻辑，避免只放孤立词组或残缺短语。内容清楚即可留白，不为填满版面或凑齐固定要点数量而硬加文字。
- **展示文字与口播严格分离**：不在页面正文中写“接下来我们看”“如下图所示”“需要强调的是”等口语串场词或空泛过渡句；连续推演、因果串讲和读图引导全部写入演讲者备注。
- **禁止防御性写作表述**：事实核查、作图取舍和内部校对在制作过程中完成。发现问题直接修正内容，**绝不把核查过程、制作意图、自我辩护、预设质疑及回应写进页面、图注、备注或逐字稿**。
- **教学示意自然呈现，条件局限就地直陈**：听众结合标题和上下文就能看出属于教学举例、类比或概念示意时，不添加“虚构示例”“仅供示意”“非实测数据”等免责声明，也不解释显而易见的箭头或连线；若呈现方式确实容易让人把示意误当成真实实验结果，直接修正标题或图内标签。真正影响结果解读的方法条件、实验范围和研究局限，在对应的方法、结果或讨论页面直接陈述具体条件与影响，不在无关页面反复附加免责套话。
- **克制页底总结框与文献脚注**：不默认在每页底部添加总结条、Key Takeaway 或参考文献脚注。仅当某页确有独立于正文、需单独突出的核心结论时才使用总结区域；仅在引用他人图表、数据或观点且需交代出处时才在页底添加简写文献来源，其余页面保持页底干净。

## 全局图文混排与图表混排约束

以下视觉与混排原则适用于任何模板风格：

- **原图原表优先**：展示已有论文或工作的方法与结果时，优先直接使用原图、原表或清晰截图，保留原始比例、图内文字、配色、图例、坐标和单位，不为迎合模板配色而照文字描述重画。原图过小或信息过密时，优先采用裁切、局部放大、分步展示或在图旁添加可编辑中文标注；只有原素材无法获取、局部处理仍无法看清、需要重新组织跨文献对比或用户明确要求重绘时，才另行制作图表并核对数值与关系。
- **图文互补与就近读图**：图或表负责呈现空间结构、机制流向或数量对比，旁文用完整长句补充背景条件、机制解释或核心观察，避免图文简单重复同一句话。把读懂图表必需的坐标含义、单位、统计口径和对比基准就近放在图表内或图旁，不让听众必须依赖口播才能读懂图。
- **版面秩序与视觉呼吸感**：按从上到下、从左到右的自然阅读顺序组织图文混排与图表混排；相互解释的图与文靠近摆放，不同信息组之间用留白或容器清晰隔开，同层级元素对齐。为主图和核心信息留出充足面积；版面放不下时先精简重复词句、优化分栏或拆页，不靠大幅缩小字号硬塞内容，也不把完整一句话拆到两页。
- **公式规范与元素可编辑性**：公式清晰排版上下标、分式和括号，在同页或紧邻位置给出关键符号含义、单位与约束条件。除原论文截图外，页面标题、正文、表格、新增标注和自制图表尽量保持独立可编辑。

## 逐字稿与演讲者备注风格

- **自然连贯的技术口语**：按连续页组写稿，使用适合直接开口朗读的完整中文句子，一段完成一个主要解释动作。写清主语、对象与指代，过长句子按因果或操作步骤自然切分；清理口误、重复套话与助手式对话用语。
- **展开机制、引导读图与自然转场**：屏幕上的书面长句已经给出主干判断，口播不再逐字照念屏幕，而是负责串起“为什么这样设计”、把笼统概念展开为具体操作步骤（如明确输入什么、更新哪部分、输出什么），并在讲图时用屏幕位置或颜色特征引导视线（先交代坐标或对比基准，再指明关键差异）。页间转场说清前一步得到了什么、为什么引出下一步。
- **内嵌备注干净可直接上台**：写入 PPT 备注时只保留可口述正文；移除参考文献列表、网址超链接、“备查/不口述”提示及“建议用时”等制作标记，清理多余空行并将段落间距设为 `0`（详见[逐字稿与备注](references/speaker-notes.md#内嵌演讲者备注)）。

## 交付前检查

交付前对照用户要求检查实际产物：

- **大纲与逐字稿**：连读主讲内容，确认开场问题得到回应、前置铺垫到位、指代与屏幕图文一致；预估时长说明估算依据，未实际试讲不写实际测得时长。
- **PPT 文件**：按[修改与交付](references/revision-delivery.md#按改动检查文件)核对最终保存的文件；在可用工具中查看页面文字、长句断行、图文混排对齐与原图清晰度，改动备注时重新读取核对备注正文与格式。交付明确的文件路径，简要说明主要改动与受环境限制未检查的项。

# PPT 内容、页面与逐字稿

围绕听众需要建立的认识组织整场讲述，让页面用凝练标题、完整书面长句、规范的 LaTeX 数学公式与清晰图表承载关键判断和依据；除非用户明确要求，默认只交付 PPT 页面，不生成逐字稿和演讲者备注。

## 明确任务、模板归属与默认交付

从请求和已有材料中确定听众背景、汇报用途、时长、参考内容、样式来源和修改范围。信息足够时直接制作或修改文件，只询问确实无法从材料推断、又会改变讲述主线或修改对象的问题；只讨论方案时交付方案。

- **默认不交付逐字稿与演讲者备注**：除非用户明确要求编写逐字稿或写入演讲者模式备注，否则默认只制作和交付幻灯片页面，不生成独立讲稿，也不在 PPT 内写入演讲者备注。
- **内容逻辑与模板样式分离**：
  - 用户提供了自定义 PPT 模板、参考课件或指定视觉风格时，直接沿用该模板的母版、配色、字体、标题区位置和版式规范。
  - 修改既有 PPT 时：若用户明确要求按照本 skill 默认风格（学术蓝风格）或指定的新模板风格进行修改，则按目标模板的配色、字体、标题区、卡片/分栏版式和长句规范对原 PPT 进行**彻底重构**，使之完全符合新风格；仅当用户未要求更换风格时，才保留既有 PPT 的原有样式。只改逐字稿或备注时不改动页面版式。
  - 用户未提供模板且未指定其他风格时，默认采用[学术蓝默认模板](references/academic-blue-style.md)（具体色值、字体字号、标题下划线与卡片版式均在该模板文档中定义）。

## PPT 制作逻辑与推进理解

### 1. 整体推进与任务分支

- **新建或重构（含将既有 PPT 重构为新模板风格）**：先明确整场要回答的核心问题和主要判断，再划分各章节职责与前后逻辑关系，随后规划连续页组，最后落定每页文字、公式与图表（仅在用户明确要求时同步编写逐字稿或备注）。每页和每项材料都要推进听众理解，合并重复铺垫、删去偏离主线的旁支。先按[检查内容方案](references/content-design.md#检查内容方案)核对大纲再生成页面；只要求大纲时在此阶段交付。
- **既有 PPT 配稿**：仅当用户要求配写逐字稿或备注时执行。通读全部页面标题、正文、图表和已有备注，按章节和连续页组起草讲稿，再对应具体页码。
- **局部修改**：先看目标页及前后衔接，判断反馈指向结构、内容深度、措辞、图文排版还是样式重构，在对应层级修改，并同步处理同文件内的同类问题与前后承接。

### 2. 内容深度与理解链条

根据章节在整场中的职责决定展开深度，使听众沿“问题从何而来 → 核心概念与方法如何运作 → 数据支持什么判断 → 边界与后续方向是什么”连贯理解：

- **背景与动机**：交代具体应用场景、已有条件及尚未解决的核心矛盾，让听众明白问题为什么重要、后文要回答什么。
- **概念与定义**：给出直观例子、核心定义、判据和必要的边界情况，使听众能据此分辨新例子；前置概念先于依赖它的页面出现。
- **方法与机制**：写清任务条件、输入表示、关键操作步骤、中间产物与输出目标，使听众能够完整走通一轮推理或计算循环，不止于罗列模块名称。
- **结果与比较**：交代比较基准、实验条件、评价指标含义与关键观察，在同一维度下横向对比，让听众看清数据支持多大范围的结论。
- **讨论与总结**：回应开场提出的问题，归纳研究贡献、适用边界及尚待验证的问题。

人名、时间、方法名、具体数值和实验条件须核对原始材料，区分预印本与正式发表版本；缺少原始依据时如实收窄结论或标明待核对，不编造数据或出处。

## 展示文字写作风格与反防御要求

| 载体 | 主要职责与写作风格 |
| --- | --- |
| 页面标题 | 用凝练的一句话或“方面：核心概括/判断”点明本页主题或结论，与章节名分工明确、不重复同一句话 |
| 页面正文与表格说明 | 用正式、客观、能独立读懂的**完整书面长句**呈现核心判断、对象、条件、机制和结果 |
| 图注与技术标注 | 仅针对需要读数或辨析机制的数据图、结果表与方法图，就近简明标注变量、单位、图例和必要条件 |
| 参考文献脚注 | **仅在必要时添加**：只在页面直接引用他人论文原图、原表、实验数据或核心观点且需注明出处时标注 |
| 演讲者备注 / 独立讲稿 | **默认不生成**；仅在用户明确要求时提供可直接朗读的自然口语解释与过渡 |

页面可见文字（含标题、正文、表格、图注和标注）统一遵循以下写作规范：

- **完整长句表述，留白优于凑字**：正文段落、分组说明与表格描述写成表意完整的句子（交代清楚研究对象、作用关系或约束条件），使听众不依赖口播也能从屏幕读懂核心逻辑，避免只放孤立词组或残缺短语。内容清楚即可留白，不为填满版面或凑齐固定要点数量而硬加文字。
- **展示文字与口播严格分离**：不在页面正文中写“接下来我们看”“如下图所示”“需要强调的是”等口语串场词或空泛过渡句。
- **禁止防御性写作表述**：事实核查、作图取舍和内部校对在制作过程中完成。发现问题直接修正内容，**绝不把核查过程、制作意图、自我辩护、预设质疑及回应写进页面、图注、备注或逐字稿**。
- **教学示意自然呈现，条件局限就地直陈**：听众结合标题和上下文就能看出属于教学举例、类比或概念示意时，不添加“虚构示例”“仅供示意”“非实测数据”等免责声明，也不解释显而易见的箭头或连线；若呈现方式确实容易让人把示意误当成真实实验结果，直接修正标题或图内标签。真正影响结果解读的方法条件、实验范围和研究局限，在对应的方法、结果或讨论页面直接陈述具体条件与影响，不在无关页面反复附加免责套话。
- **克制页底总结框与文献脚注**：不默认在每页底部添加总结条、Key Takeaway 或参考文献脚注。仅当某页确有独立于正文、需单独突出的核心结论时才使用总结区域；仅在引用他人图表、数据或观点且需交代出处时才在页底添加简写文献来源，其余页面保持页底干净。

## 全局图文混排、图表混排与公式约束

以下视觉与混排原则适用于任何模板风格：

- **原图原表优先**：展示已有论文或工作的方法与结果时，优先直接使用原图、原表或清晰截图，保留原始比例、图内文字、配色、图例、坐标和单位，不为迎合模板配色而照文字描述重画。原图过小或信息过密时，优先采用裁切、局部放大、分步展示或在图旁添加可编辑中文标注；只有原素材无法获取、局部处理仍无法看清、需要重新组织跨文献对比或用户明确要求重绘时，才另行制作图表并核对数值与关系。
- **灵活生成学术风格配图与插画**：配图与插画**不强制使用流程图或 PPT 原生形状手工拼搭**。在展示研究背景、应用情境、复杂抽象概念或宏观直观示意时，若原生图形难以直观传达或表现力不足，优先考虑调用图片生成工具直接生成符合学术审美、易于理解的插画进行配图（确保画面内容与当前上下文一致；精确实验数据与真实论文结果仍采用原始图表或数据作图）。
- **按图表性质决定图文配合深度**：并非所有图或表都需要文字解释和读图说明。对于承载核心论证的**实验结果图、总结对照表、系统架构图与方法流程图**，旁文用完整长句补充条件、机制解释或核心观察，并在图旁就近标明必要的坐标、单位、统计口径和对比基准；对于用于说明研究背景、帮助直观理解或美化版面的**场景配图与学术插画**，无需强行配写图注、坐标条件或专门的解说文字。
- **专业数学公式（LaTeX 形式）与可编辑性**：公式与行内数学符号必须使用专业的数学公式形式（按 LaTeX 数学语法生成原生可编辑公式对象或高分辨率 LaTeX 数学公式，规范呈现分式、根号、上下标、求和号与希腊字母，如 $d_{\text{model}}$、$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$，**严禁在页面上使用 `d_model`、`h_(t-1)`、`10000^(2i/d_model)` 等纯文本下划线或脱字符近似写法**）。除原论文截图和生成的插画外，页面标题、正文、表格和新增标注尽量保持独立可编辑。
- **版面秩序与视觉呼吸感**：按从上到下、从左到右的自然阅读顺序组织图文混排与图表混排；相互关联的元素靠近摆放，不同信息组用留白或容器清晰隔开，同层级元素对齐。版面放不下时先精简重复词句、优化分栏或拆页，不靠大幅缩小字号硬塞内容。

## 逐字稿与演讲者备注风格（仅在用户明确要求时启用）

当用户明确要求提供逐字稿或演讲者备注时遵循以下规则：

- **自然连贯的技术口语**：按连续页组写稿，使用适合直接开口朗读的完整中文句子，一段完成一个主要解释动作。写清主语、对象与指代，过长句子按因果或操作步骤自然切分；清理口误、重复套话与助手式对话用语。
- **只解说核心图表，不解释装饰配图与插画**：屏幕上的书面长句已给出主干判断，口播重在串起推导因果并把笼统概念展开为具体动作。**逐字稿不强制说明 PPT 中的每一张图**：只针对结果图表、总结表、流程图、架构与方法图等需要明确解释才能理解的图表进行指图引导和解读；对于研究背景配图、场景插图和美观性插画，逐字稿中明确不进行解释。
- **内嵌备注干净可直接上台**：受命写入 PPT 备注时只保留可口述正文；移除参考文献列表、网址超链接、“备查/不口述”提示及“建议用时”等制作标记，清理多余空行并将段落间距设为 `0`（详见[逐字稿与备注](references/speaker-notes.md#内嵌演讲者备注)）。

## 交付前检查

交付前对照用户要求检查实际产物：

- **PPT 文件**：按[修改与交付](references/revision-delivery.md#按改动检查文件)核对最终保存的文件；在可用工具中查看页面文字、LaTeX 公式与数学符号排版、长句断行、图文混排对齐与图片清晰度；未要求写备注时确认未塞入多余备注文本。
- **大纲与逐字稿（如本次要求交付）**：连读确认开场问题得到回应、前置铺垫到位、关键图表解读与页面一致；预估时长说明估算依据，未实际试讲不写实际测得时长。

交付明确的文件路径，简要说明主要改动与受环境限制未检查的项。

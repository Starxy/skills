# 页面与图表

本文件规范全局视觉载体选择、原图原表与学术插画生成、图文混排与图表混排深度、专业 LaTeX 数学公式及版面秩序，适用于任何 PPT 模板。

## 先确定样式来源

按 [SKILL.md 模板归属原则](../SKILL.md#明确任务模板归属与默认交付)确定样式：
- 用户提供自定义模板或指定外部参考课件时，观察原稿的母版、标题区位置、配色、字体、分栏与容器风格、图表占比及页脚格式，在制作或修改内容时沿用这套视觉规范。
- 修改既有 PPT 时：若用户明确要求按本 skill 默认风格（学术蓝风格）或新模板风格修改，则按目标模板规范对原 PPT 进行**彻底重构**，使配色、标题区、版式和字体全面符合新风格；仅当用户未要求更换风格时，才保留既有 PPT 的原有样式。
- 用户未提供模板且未指定其他风格时，读取[学术蓝默认模板](academic-blue-style.md)。

学术 PPT 最基本的要求是**清晰、规范、重点突出**：每个字、每张图都要让现场观众看清（字号、清晰度与对比度足够），并严格遵循**“文不如字、字不如表、表不如图”**的表达优先级——能用清晰图表呈现就不堆砌表格，能用结构化表格归纳就不堆砌文字，必须用文字时分层次排布并突出关键词，让听众能够“一目十行”抓住重点与亮点，切忌大段罗列文字。页面文字句式、标点（全篇无中文句号、问题不用问号）、反防御要求与按需文献脚注格式遵循[展示文字写作风格与反防御要求](writing-style.md)。

## 选择视觉载体与学术插画生成

| 要表达的内容 | 优先选用的载体 | 应保留或注意的要点 |
| --- | --- | --- |
| 论文或已有工作的结果与方法 | 原论文图、原表或清晰截图 | 保留原图例、指标、坐标、单位、条件与比较对象 |
| 数量变化与分布对比 | 用实际数据绘制的原生图表 | 数据来源、单位、统计口径及必要误差范围 |
| 方案、复杂条件或消融对照 | 同维度表格 | 比较维度、具体差异与关键结论 |
| 机制、流程与系统框架 | 原机制图、可编辑节点流程图或生成的直观学术插画 | 节点关系、方向、输入输出与核心过程；**不强制写死为卡片节点**，结构简单需改字时用 PPT 节点，耦合复杂时用生成插画或原图 |
| 分点研究内容或方法总览 | **先总览后分点页**（生成总览插画或 PPT 形状架构图） | 在分点一 / 二 / 三细讲之前展示整体定位、先后依赖与协同关系（推荐但不强制） |
| 操作与动态现象 | 已核验的演示或视频 | 初始条件、展示过程与需要观察的部位 |
| 研究背景、场景或抽象概念示意 | **生成的学术风格插画**、切题配图或简图 | 与当前研究背景和上下文一致，直观易懂 |

- **原文图表优先**：展示论文或已有工作成果时，优先使用原图、原表或清晰截图，保留图内文字、配色、图例和坐标单位，不为了迎合模板配色而照文字描述重画一套。原图太小或细节过密时，优先采用裁切、局部放大、分步展示或图旁加中文标注；只有原素材无法获取、局部裁切仍看不清、需要重新组织跨工作比较或用户明确要求重绘时，才另行作图并核对数值和关系。
- **绘图与制表统一规范**：自绘图表与表格须做到图题、表头清楚明确，坐标轴、单位、图例与比较条件符合学术惯例；同一套 PPT 中同类图表的标识风格、字号大小、线宽与色彩含义须前后统一，确保投影观看距离下所有标注与数据清晰可辨。
- **按复杂度灵活选择卡片节点或图片生成插画**：框架图、机制流向图与分点方法总览图**不强制使用 PPT 原生形状或卡片式节点拼接**。当节点少、步骤线清晰且需要直接编辑文字标签时，可用可编辑的 PPT 卡片、形状与箭头；当展示研究背景、应用情境、跨层耦合机制或直观总览，原生框线难以清晰表达时，优先调用图片生成能力直接生成白底、符合顶刊科研审美的插画进行配图。生成插画应与整套 PPT 的主色系协调，同时**按图示语义适当引入低饱和度的互补色与功能辅色**（如柔和的珊瑚红、鼠尾草绿、暖琥珀、灰紫等）来区分正反状态、不同模块或信号路径，不把生成图强行压成单色蓝灰，也不能拿生成式图片冒充真实实验结果或伪造论文截图（使用默认学术蓝模板时的具体推荐色板见[学术蓝配色与插画规范](academic-blue-style.md#原文图表插画与按需脚注)）。

## 图文混排与图表混排深度

根据图件在页面中的实际用途决定是否配写说明文字，不搞一刀切：

- **结果图表、总结表、流程图与方法机制图**：图或表负责呈现空间结构、机制流向或数量对比，旁文用提纲挈领的分层短句补充实验条件、机制解释或核心观察并突出关键词，避免图文简单重复同一句话。把读懂这类图表必需的指标含义、坐标、单位、样本范围和对比参照就近放在图旁或图注里，让听众不依赖口播也能看懂图表。
- **研究背景配图、场景插图与美观性插画**：主要作用是帮助听众直观代入情境、辅助理解抽象背景或平衡版面视觉。这类配图和插画只需与页面主题协调，**不需要强行配写解释段落、图注或坐标条件说明**。
- **文献脚注按需添加，不每页都加**：只有页面直接引用了他人论文原图、原表、数据或需要标明出处的观点时，才在页底按[文献脚注格式与示例](writing-style.md#4-克制总结框与按需添加参考文献脚注)添加简写来源；无需每页都在页底堆放通用注释框。

## 版面层次、多栏与图文混排多样性

排版的根本原则是**对齐**与**适度留白**：按从上到下、从左到右的阅读习惯排列内容，页面元素的上下左右边界、标题基线、多栏间距与图文轴线须严格对齐并均匀分布；在整齐对齐的基础上，版面四周与模块之间留出适度空白，既不空洞也不拥挤。相互关联的元素靠近摆放，不同信息组用留白、分隔线或当前模板的分组容器隔开。基于已确定的大纲逐页选择最契合当前页信息关系的版式，**避免整套 PPT 陷入单一两栏布局，不把特定主题锁死在固定版式上，也不复刻参考模板或示例 PPT 的整套页面组织序列**：

- **灵活组织图文混排**：依据内容重点选用左图右文、右图左文、上图下文、上文下表、主问题配两三个子问题与插画，或全宽总览图配底部要点等格局；例如“科学问题”页面不固定采用“上问题条下表格”，更常见的材料可直接用纯文字层次、一个主问题加两三个分解子问题，或科学问题配直观学术插画。
- **合理运用多栏混排**：除双栏并列外，遇到三个并行模块、三种机制或三项对照时使用**三栏卡片或三栏图文混排**；遇到四个并行策略、四维设置或四项特征时使用**四栏图文混排**（每栏配小型示意图或统计简图加精炼分层要点），注意随栏数增加适当收紧单句字数与字号，留足栏间留白。
- **分点展开前增设总览页（建议）**：当连续数页依次介绍研究内容一二三或方法步骤一二三时，建议在其前方安排一页总览图呈现各分点的定位与关系（详见[内容设计](content-design.md#由大纲落到单页与连续页组衔接)）。

**默认文字间距与断行秩序**：合理设置字符间距、行间距与段距可显著提升学术页面的整齐度与可读性——正文及卡片内段落默认采用 **行间距 `1.2` 倍、字间距 `1 pt`（OOXML `<a:rPr spc="100"/>`）、段落间段前 `6 pt`**（`space_before = 6 pt`，首段不额外顶空；紧凑表格、图注及页脚可按空间适度收紧）。让句子自然断行，避免逐字折断、句首孤立标点或单字成行。给主图和关键文字留出舒展空间；版面放不下时先精简重复词句、改用图表或拆页，不靠大幅缩小字号硬塞内容，也不要把一句话拆到多页。

**学术配色风格（文字三色严控，辅色只约束图表与插画）**：学术 PPT 以规范、清晰展示成果为第一目标，推荐**低调、简约、亮度偏低的扁平化色系**，整套 PPT 配色方式前后一致，不追求妖艳、炫酷或绚丽效果，避免过多色彩分散注意力。
- **页面文字严格限定三色 + 脚注灰**：正文与标题文字只采用三种颜色——**主色（如学术深蓝）**用于标题、小标题与前置关键词，**黑色**用于正文、表格主体与公式，**学术红**仅用于少量核心结论词、关键问题或突出数值强调；**灰色仅用于页底参考文献脚注及轻量页码**。**严禁在正文文字、并列小标题或卡片顶条上使用绿色、粉色、紫色等多种对比颜色**。
- **互补与功能辅色只用于图表与插画**：上述低饱和、偏低亮度的顶刊科研互补色（如柔和砖红/珊瑚、鼠尾草绿、暖琥珀、灰紫等）**仅用于自绘数据图表、对比柱线、热图与生成的学术插画**，用来清晰区分数据系列、正反状态或不同模块，打破单色蓝灰疲劳，同时保持全篇图表色彩语义一致，拒绝高饱和荧光色或杂乱彩虹堆砌。

**禁止使用商业或大屏风格的“超大数字 / KPI 指标卡”**（即把单个数值、语料规模或百分比放大到 `30 pt` 以上单独居中占去卡片主体、下方仅垫一两行小字）；除封面、章节页标题与目录编号外，内容区任何数字和指标的字号不得高于本页居中标题，通常随正文或卡片小标题同级排布，需突出时依靠加粗、少量学术红强调、结构化表格或实际数据图表呈现。规模参数与背景统计应融入精炼句子、紧凑信息表或数据分布图，不单独抽出来做大字报。只保留少数确有独立价值的结论框或高亮条，其余页面把空间留给实质内容和留白。

## 公式与可编辑性

- **使用专业的数学公式（LaTeX 形式）**：独立公式与正文、表格中的行内数学符号均采用专业的数学公式排版（以标准 LaTeX 数学语法编写，生成演示文稿原生可编辑公式对象或高分辨率 LaTeX 数学渲染）。规范呈现上下标、分式、根号、括号、算子与斜体变量（例如写作 $d_{\text{model}}$、$h_{t-1}$、$\mathcal{O}(n^2 \cdot d)$、$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$），**不在页面上直接输出 `d_model`、`h_(t-1)`、`10000^(2i/d_model)` 等纯文本近似符号**。
- **符号说明与可编辑性**：关键公式在同页或紧邻位置给出符号含义、单位与约束条件；长公式按推理步骤拆分展示。除原论文图、生成插画或复杂公式渲染图外，页面标题、正文、分组框、表格、新增标注和原生数据图表尽量保持独立可编辑。
- **跨软件（Microsoft Office PowerPoint 与 WPS）OOXML 元素顺序兼容**：通过代码或 XML 操作生成 `.pptx` 时，必须严格遵守 OpenXML（`dml-main.xsd`）的子元素顺序要求——Microsoft PowerPoint 采用严格的顺序解析器，顺序错误的元素会被直接丢弃并回退为默认黑色边框或默认项目符号（WPS 则不校验顺序）：
  - **表格单元格 `<a:tcPr>`**：边框节点 `<a:lnL>`、`<a:lnR>`、`<a:lnT>`、`<a:lnB>` **必须排在填充节点 `<a:solidFill>` 之前**（若先调 `cell.fill.solid()` 再 `append` 边框，Office PowerPoint 会忽略自定义边框颜色并回退为黑色粗框）。
  - **段落属性 `<a:pPr>` 与 `<a:lstStyle>`**：行距 `<a:lnSpc>`、段距 `<a:spcBef>`/`<a:spcAft>` 和无项目符号 `<a:buNone/>` **必须插入在 `<a:defRPr>` 之前**（若 `append` 在 `<a:defRPr>` 之后，Office PowerPoint 会忽略 `<a:buNone/>`，导致占位符标题前多出圆点符号 `•`）。

## 检查实际版面

文件保存后，在可用软件或渲染结果中按实际展示比例通读新建或改过的页面：

- 核对所有可见文字（含标题、核心问题框、正文、表格、图注和脚注）是否符合[展示文字写作风格与反防御要求](writing-style.md)（提纲挈领、分层次突出关键词、无大段文字堆砌、用语前后一致、**无任何中文句号 `。`**、**科学问题与核心问题无问号 `？`**、无防御性套话、按需文献脚注格式合规）；
- 检查 LaTeX 数学公式与行内数学符号是否规范美观（无纯文本 `_` 或 `^` 裸露），以及字号清晰度、文字间距（默认行距 1.2 倍、字距 1 pt、段前 6 pt）、图表图题与表头标识一致性、上下左右对齐、均匀留白、遮挡与纵横比。

发现文字、标点、公式或排版问题直接修改保存，复查受影响页面后再交付。若当前环境没有渲染或打开工具，如实说明尚未检查实际画面效果。

# 展示文字写作风格与反防御要求

本文件规范 PPT 页面上所有可见文字（章节栏、页面标题、核心问题框、正文段落、表格说明、图注与页底文献脚注）的句式、标点、括号、文风、反防御要求及参考文献脚注格式。

## 1. 页面文字载体的职责分工

| 载体 | 主要职责与写作风格 |
| --- | --- |
| 章节栏标题 | 简短标明当前所属章节编号与名称，统领本组页面 |
| 页面标题 | 用凝练的一句话或“方面：核心概括/判断”点明本页主题或结论，与章节名分工明确、不重复同一句话 |
| 核心问题 / 定义条 | 用客观陈述句交代本页或本节要解决的科学问题、形式化定义或核心设定，不使用疑问句和问号 |
| 页面正文与表格说明 | 用正式、客观、能独立读懂的**完整书面长句**呈现核心判断、研究对象、作用机制、实验条件和结果 |
| 图注与技术标注 | 仅针对需要读数或辨析机制的结果图、数据表与方法图，就近简明标注变量、单位、图例和必要条件 |
| 参考文献脚注 | **仅在必要时添加**：只在页面直接引用他人论文原图、原表、实验数据或核心观点且需注明出处时于页底标注 |
| 演讲者备注 / 独立讲稿 | **默认不生成**；仅在用户明确要求时提供可直接朗读的自然口语解释与过渡（详见[逐字稿与备注](speaker-notes.md)） |

## 2. 句式与标点硬性约束

- **完整书面长句表述，留白优于凑字**：正文段落、分组说明与表格描述写成表意完整的句子（交代清楚研究对象、作用关系、约束条件或观察结果），使听众不依赖口播也能从屏幕读懂核心逻辑，避免只堆砌孤立词组或残缺短语。内容表达清楚即可留白，不为填满版面或凑齐固定要点数量而硬加文字。
- **原源术语、主动语态与要点先行**：写作时使用用户和资料源所用的术语。保留技术细节，在能提升解释精确性时使用领域专用语言。采用主动语态，将紧密相关的细节放在一起。先阐述关键要点，避免使用读者只有读到后续部分才能理解的指代，并提供充足语境以便理解推理过程。
- **严禁出现任何中文句号（`。`）**：PPT 页面中的所有可见文字（包括标题、核心问题框、卡片正文、列表说明、表格单元格、图注与文献脚注）**禁止出现任何中文句号 `。`**。句末直接收束，不加中文句号；同一段落或单元格内包含多层分句时，使用中文逗号 `，`、分号 `；` 或顿号 `、` 连接（英文小数点、缩写点及数学公式中的点号正常保留）。
- **科学问题与核心问题严禁出现问号（`？` / `?`）**：科学问题、核心问题、研究动机、章节名及页面标题等表述**禁止使用疑问句和问号**，严谨的学术表达统一采用陈述句说明研究矛盾、待建立的机制或待检验的关系：
  - 正例：`核心问题：在不依赖序列逐步递推的条件下建立任意位置间的全局依赖并保持并行训练效率`
  - 反例：`核心问题：如何摆脱序列逐步递推并实现高效的全局并行计算？`
- **规范括号使用与解释性括注语义改写**：
  - 不使用括号承载同义复述、自我解释、用途说明、制作意图、处理状态或非必要限定。
  - 冗余内容直接删除；包含有效信息的括注，应融入主句、标题或独立标签，不得丢失重要信息。
  - 正规术语、必要缩写、数学和统计表达、规范编号、真实引文中的必要括号允许保留。
  - 最终检查每个可见文本框，对解释性括注进行语义改写，而不是机械删除。
- **展示文字与口播严格分离**：不在页面正文中写“接下来我们看”“如下图所示”“需要强调的是”“本页主要介绍”等口语串场词或空泛过渡句。

## 3. 禁止防御性写作表述

- **不将讲解稿、制作说明、免责声明或审稿式补充放入页面正文**：事实核查、作图取舍和内部校对在制作过程中完成。发现问题直接修正页面内容，**绝不把核查过程、制作意图、自我辩护、预设质疑及预防性回应写进页面、图注、备注或逐字稿**（例如不写“已核对原表数据”“为避免误解特说明如下”）。
- **教学示意自然呈现，不加免责声明**：听众结合标题和上下文就能看出属于教学举例、类比或概念示意时，不添加“虚构示例”“仅供示意”“非实测数据”等免责标签，也不解释画面中显而易见的箭头或连线；若呈现方式确实容易让人把示意误当成真实实验结果，直接修正标题或图内标签本身。
- **方法条件与研究局限就地直陈**：真正影响结果解读的方法前提、实验范围和研究局限，在对应的方法、结果或讨论页面直接陈述具体条件与影响，不在无关页面反复附加免责套话。

## 4. 克制总结框与按需添加参考文献脚注

- **克制页底总结框**：不默认在每页底部添加总结条或 Key Takeaway。仅当某页确有独立于正文分栏、需单独突出的核心结论时才设置总结区域，其余页面保持页底干净。
- **仅在必要时添加参考文献脚注**：不在所有页面底部添加文献脚注。只在页面直接引用了他人论文原图、原表、实验数据或特定核心观点且需注明出处时才在页底标注；展示本人工作、宏观背景、通用公式推导、流程梳理或总结讨论时不加文献脚注。
- **脚注参考文献格式与示例**：
  - 单条格式：`研究机构（多个机构用顿号“、”分隔），第一作者姓 等，论文完整标题，发表会议/期刊与年份`
  - 多条连接与标点：同页引用多篇文献时条目间用中文分号 `；` 分隔，按页面无中文句号规则，条目末尾不加中文句号 `。`。机构名称优先使用中文通用简称（如高校与常见机构中文名）或领域内通用的英文名称（如 `MIT`、`DeepSeek-AI`、`Google Brain`）。
  - **Few-shot 示例**：
    ```text
    南京大学、百度、电子科技大学，Liu 等，ChessArena: A Chess Testbed for Evaluating Strategic Reasoning Capabilities of Large Language Models，ACL 2026
    哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model Implicit in a Generative Model，NeurIPS 2024
    DeepSeek-AI，Guo 等，DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning，Nature 2025
    哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model，NeurIPS 2024；
    ```

# worldmodels 默认模板

本文件定义 worldmodels 模板的样式，作为新建 PPT 的默认模板，适用于不同主题，无需用户额外指定。模板选择及既有文件的样式保留遵循 [SKILL.md](../SKILL.md#确定本次任务)。

## 已确认的样式

| 项目 | 要求 |
| --- | --- |
| 背景与标题区 | 白色背景，浅灰标题条 `#EDF0F4`，不设置蓝色顶条 |
| 全套一致性 | 标题字体、同层级字号、间距、图例、脚注和章节页统一；替换内容后继承这些格式 |
| 章节过渡页 | 简洁，以大标题为主；小标题按内容需要设置，层级与格式保持一致 |
| 页面正文标点 | 句末不加句号；小数、缩写和公式中的点正常保留。逐字稿仍使用正常标点 |
| 来源脚注 | 有实际引用时采用 `机构，研究者，论文名（全称或简称），正式期刊／会议或资料类型及年份`；是否创建页脚按[页面与图表](visual-design.md#图文互补与读图)处理 |
| 来源版本 | 有正式发表版本时优先使用；预印本、讲义和演示按实际类型标识，不补造发表渠道 |
| 脚注详略 | 省去图号、表格行号、长段解释和网址；这些定位信息放入独立备课资料，影响读图的指标与条件放在图旁 |

## 可调整的起点参数

| 项目 | 起点 |
| --- | --- |
| 画布 | 16:9，约 13.33 × 7.5 英寸 |
| 中文字体 | 微软雅黑或思源黑体，按环境可用字体与实际渲染调整 |
| 字号 | 标题 30 pt，小标题 24 pt，正文 22 pt，图注 16 pt，来源与页码 11 pt |
| 间距 | 标题区高约 0.85 英寸，左右边距约 0.55 英寸，正文距标题区约 0.25 英寸，正文行距约 1.15–1.25 |
| 文字颜色 | 主要文字 `#20242A`，次要说明 `#59636E`，强调色按内容选择 |

这些数值用于起步，按用户确认的样例和投影可读性调整，不设固定每页字数或图文比例。正文、标题和结论区域遵循[页面正文与讲稿](../SKILL.md#页面正文与讲稿)。模板只约定视觉样式，历史课件中的某次开场、章节页数和时长分配不随模板继承。

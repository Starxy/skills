# 内容设计

本文件从 PPT 整体到局部，规定学术汇报的根本目的、**三阶段内容设计流程**（需求与场景确认 → 纯逻辑简要大纲 → 面向展示的逐页详细设计）、分场景构思策略、讲解深度与页间连贯控制，以及材料核查与时间分配。

## 明确 PPT 的目的：内容为核心，形式服务于表达

PPT 的核心目的是**高效传递信息、讲清楚、让人听明白并便于讨论交流**。一场有效的学术演讲由**内容、形式、表现**三者协同作用：

- **内容**决定演讲的学术价值，是整场汇报的核心；
- **形式**是连接内容与现场表现的桥梁，用来把有价值的学术内容转化为听众容易理解、演讲者容易讲清楚的信息，从而提高信息传递效率；
- **表现**影响现场交流效果。

三者相互配合，但**绝不为了追求固定形式反过来束缚或削弱内容**；所有章节划分、信息密度与呈现形态都以帮助听众高效理解为唯一尺度。

## 三阶段内容设计

新建或整体重构 PPT 时，严格按以下三个阶段推进，把“明确诉求”“组织汇报逻辑”与“细化页面展示”分开处理，避免过早被版面格式束缚导致汇报逻辑松散，也避免缺少逐页细化而边做边拼：

### 第一阶段：确认场景、基本要求与材料支撑

- **确认适用场景与基本要求**：动笔前先与用户确认 PPT 的适用场景（如课题开题/中期/结题/学术交流/课题简介、论文精读分享、课程或专题讲座等）以及基本要求，包括汇报目标、听众背景、预期页数或时长、是否已有指定章节划分与模板要求；未明确时及时提问，必要时继续追问。
- **评估材料是否足以支撑**：通读用户提供的论文、文稿、数据、图表或既有文件，判断是否具备支撑目标汇报所需的核心论点、方法细节、结果数据与原始图件。缺少关键内容或存在事实冲突时，列出缺口并请用户补充，不靠臆造内容凑页。

### 第二阶段：纯汇报逻辑的简要大纲设计（交付用户确认）

- **阶段边界——只聚焦如何讲好一场汇报**：通读全部可用资料，严格按第一阶段确定的场景与目标构思简要大纲。**本阶段不考虑版面设计约束、不考虑模板组件或展示文字句式/字号/配色约束**，只关注如何组织汇报逻辑——包括整场汇报的主线思路、学术故事如何展开、章节如何划分以及信息如何递进。
- **简要大纲须定清的核心内容**：
  1. **锁定唯一主题思路与学术故事主线**：用一句明确的话写清整场汇报要建立的核心判断、要解开的核心问题，或要带听众完成的认知推进。全部章节与材料取舍均围绕这条主线运转，不能推进主线的支线、铺垫或陪衬直接合并或删减。
  2. **按场景与课题自身逻辑划分章节**：结合下文[分场景内容设计策略](#分场景内容设计策略)，按当前课题最自然的论证或讲述路径决定章节数量、顺序、名称和各部分篇幅权重（用户已指定章节时予以保留），不照搬示例模板的章节骨架与页序。
  3. **确定目录划分、总页数与各页逻辑职责**：列出完整目录、合理的总页数，以及每页或连续页组在学术故事线中负责推进什么判断、大致依托哪些原始材料。
- **交付与确认闭环**：完成[第二阶段简要大纲自检](#检查内容方案)后，向用户交付一份**简要大纲 Markdown 文档**，并在回复中说明**目录划分、总页数与简要汇报逻辑**供用户确认；若用户提出修改事项，按反馈调整大纲文档并再次说明。**待用户确认大纲后，再进入第三阶段**（若用户已直接提供明确大纲设计稿，核对其与材料、场景匹配且无重大缺口后，可直接进入第三阶段）。

### 第三阶段：面向展示的逐页详细设计（完成后直接制作 PPT）

用户确认大纲后正式开始本阶段。此时在已定全局思路、汇报主线与章节划分的框架内，引入模板规范、页面布局合理性与展示文字表达约束，产出一份可直接驱动制作的**逐页详细设计 Markdown 文档**：

- **结合模板、版面与展示文字规范细化每一页**：同步参照目标模板（默认见[学术蓝默认模板](academic-blue-style.md)）、[展示文字写作风格与反防御要求](writing-style.md)与[页面与图表](visual-design.md)，为每一页写明：
  - 所属章节、页码与本页一句核心观点标题；
  - **页面排版与布局方案**：依据本页信息关系及目标模板特点确定最合适的载体与空间结构（无框分层文字、图文混排、表格、原生图表、多栏并列或总览图等），确保布局合理、主次清晰；
  - **页面实际展示文字**：按书面化、提纲挈领、分层次突出关键词、适合现场快速扫读的标准写清上屏文字（无中文句号、问题不用问号、去解释性括注），不照搬大段论文原文；
  - **图表、插画与公式安排**：明确引用哪张原图/原表、绘制何种统计图、生成何种白底学术插画、放置哪些 LaTeX 数学公式，以及是否需加文献脚注。
- **通盘兼顾页面之间的连贯性**：逐页设计时同步审视相邻页面与连续页组之间的逻辑承接、术语与符号一致、前文悬念与后文回应，以及相邻页版式节奏的自然变化（细则见下文[由大纲落到单页与连续页组衔接](#由大纲落到单页与连续页组衔接)）。
- **直接转入 PPT 制作**：完成[第三阶段逐页详细设计自检](#检查内容方案)并得到逐页详细设计文档后，**直接根据目标模板要求和图表设计要求开始制作 PPT**，无需再次暂停等待确认（仅当细化过程中暴露出此前未发现的重大事实或核心素材缺口时，才向用户补充确认）。

## 分场景内容设计策略

先判断当前任务属于哪类汇报场景，再选用对应策略组织大纲与推进逻辑；同一场汇报若兼具多种诉求（例如课题汇报中穿插关键论文方法），以主场景定骨架，局部环节吸收对应做法。

注意：下列各场景的要点规范的是**构思大纲时的内部思考主线，而不是照字面写进目录或幻灯片的章节名与页标题**（例如不要机械设置名为“由背景引出痛点”“凝练提出科学问题”的章节或页面）。实际目录名称与章节取舍须贴合具体场合与受众习惯。

### 课题汇报（开题、中期、结题、学术交流与课题介绍）

- **大纲构思主线（思考逻辑）**：先交代研究背景（领域或疾病背景、现实重要性与已有基础）并落到具体研究场景，由真实场景收束出现时痛点与现有局限，从中提炼高度凝练的科学问题（陈述句，不堆砌零散需求；可设一个核心问题，必要时辅以两三个紧扣主线的子问题），再拆解对应需要攻克的关键技术难点，随后围绕科学问题与技术难点展开研究框架与具体研究方法（分点展开前建议前置总览图），并按汇报场合承接研究基础、验证结果或预期成果。
- **参考目录章节（参考但不强制，按场合灵活增删）**：
  - 默认参考目录：**研究背景** → **研究场景** → **现时痛点** → **科学问题** → **技术难点** → **研究方法**。
  - 具体目录章节可随场合实际需求增删或合并，不硬凑固定板块——例如正式开题、立项或基金答辩可在“研究方法”后按需补充“研究基础”“计划安排”“预期成果”；中期或结题汇报可将后段重点转向已完成工作与验证结果；短时学术交流或课题简介也可按内容紧密度合并相邻章节。

### 论文分享（组会精读与文献报告）

核心目标是还原论文真正有启发性的核心思路与有效范围，而不是机械复述论文目录：

1. **先抓核心洞见与切入点**：直指这篇工作要打破的旧假设、解决的关键矛盾或提出的核心想法，压缩泛泛的领域通史。
2. **顺着论文自身论证节奏排布**：按论文最自然的推理路径组织大纲（如“直觉设想 → 机制构建 → 递进验证与反常失效剖析 → 关键修补”或“问题诊断 → 核心设计 → 消融对照与边界”），不把每篇论文都压进同一套固定章节数与页序。
3. **方法讲清运作，实验重在结论、条件与消融**：优先使用论文原图原表；机制部分围绕最关键的设计选择与必要公式讲通运作逻辑，实验部分精选能检验核心论断的主对比、消融与典型案例，不铺陈全部附表。
4. **收束于边界与延伸启发**：直接交代方法前提、适用范围、已知局限，以及对当前研究方向或组内工作的可借鉴之处。

### 讲座（课程讲授、专题报告与领域综述）

核心目标是以听众的认知构建为中心，由浅入深建立直觉理解与系统框架：

1. **从直觉、现象或具体问题切入**：先用听众熟悉的场景、直观例子或反差现象建立认知锚点，再逐步过渡到抽象概念、术语与形式化定义，避免开篇直接堆叠大段公式与名词。
2. **用主案例或清晰演进线贯穿深化**：精选一两个贯穿主线的代表案例或技术演化脉络，每次回到同一案例都引入更深一层机理、约束条件或对比视角，减少互不关联的碎片罗列。
3. **控制概念密度并铺好认知台阶**：只在下一步真正需要时引入新概念；跨阶段转换或并列比较多种路线时提供简要的全局定位或对照视图，帮助听众看清当前所处位置。
4. **保留辨析点与带得走的框架**：在常见误区、关键取舍或开放问题处留出思考落点，结尾收束为结构化的核心结论与延伸学习线索。

## 围绕主题主线控制深度与推进理解

不再用固定栏目清单规定每一类页面必须怎么写，而是紧扣已锁定的主题思路与听众理解链条，按以下四条原则掌握各部分深度：

- **详略服从主线，不为凑板块平均用力**：直接支撑核心判断的关键机制、决定性转折、核心数据对比或关键取舍要给足空间讲透；仅起前提铺垫、次要对照或背景交代作用的内容从简处理，能融入相邻页面就不单独撑成一章。
- **按认知依赖排序，不按刻板顺序堆砌**：定义、符号、任务条件或背景事实在听众真正需要用到之前交代即可，不必全部堆在开头；关键现象、核心结果或反常失效也可以前置抛出以立住主线，再回头拆解原因与机制。只要每一步讲述结束时听众已具备进入下一步所需的全部前提，顺序就成立。
- **每个部分推进实质推理，不流于标签化罗列**：讲机制或方法时说清输入、关键变换、中间产物与输出，让听众跟得上一轮真实运转，不止于罗列模块名；讲实验、数据或对比时写清比较维度、测试条件与结论适用边界，不孤立报数字；讲局限或后续方向时落到具体失效机理或约束条件，不写放之四海而皆准的套话。
- **复现同一素材须推进新认识**：同一项工作、方法或案例若在前文定位后再次出现，须按新位置的目标错开写法，每次再出现都引入更深一层机理、新条件或新判断，不重复铺垫同一遍背景。

## 由大纲落到单页与连续页组衔接

基于已确认的大纲设计具体页面时，让页面形态服从大纲中这一页的内容任务：

- **按该页信息关系决定版式，不反过来拿版式框定内容**：先看大纲里这一页要表达的是单点深化、因果转折、对照权衡、机制拆解还是大图细读，再决定用文字分层、图表混排、多栏并列还是全幅图示。整套 PPT 的页面组织节奏因题而异，不沿用示例 PPT 的起承页型或固定卡组序列。
- **连续页组自然承接**：允许多页合力讲透一个复杂机制，也允许一页承载相连的判断；前文立下的主线命题、矛盾或悬念，后文须有明确呼应与落点。
- **分点汇报建议前置总览页（建议而非强制）**：当某部分在逻辑上确实按“研究内容 / 方法 / 路线一、二、三”并列或递进拆讲时，建议在逐点细讲前安排一页汇总总览图，集中呈现各分点之间的逻辑关系及其在整场主线中的定位（可用图片生成或 PPT 原生形状与连线构建）；若当前部分属于单线叙事、案例演进或问题追因，则无需硬加总览页。
- **跨层级理解阶梯**：从直观例子过渡到形式化表达前先交代符号对应的实际对象；从方法原理进入实验或落地前交代测试条件与现实约束。

局部修改既有 PPT 时，先通读目标页所在部分及前后相连页面，理清它在整场主线和连续页组中的位置后再改动，并同步处理前后承接。页面与口播的职责边界遵循[展示文字写作风格与反防御要求](writing-style.md#1-页面文字载体的职责分工)：口语串场和过渡句留在讲稿中，页面只呈现客观的问题、条件、机制与结果。

## 材料选择与事实核查

每页和每项上屏材料都要推进整场主题思路，合并重复铺垫、删去偏离主线的旁支。选材时依据当前页在大纲中的实际任务取舍：交代前提只保留理解矛盾所需的最小上下文；阐释机制写清输入、核心过程与输出，必要时用单一案例贯穿；横向比较须核对各方案的数据集与实验条件处于同一维度；展示演示或案例时说明展示对象与初始条件。

人名、发表时间、方法名、具体数值和实验条件须核对原始论文、官方说明或作者材料，分清预印本与正式发表版本。缺少原始依据时如实标明待核对之处、收窄结论范围，不编造数字或出处；用户限定只用所附材料时，不超出该材料范围。

梳理脉络时区分时间先后、思想相近与明确启发；使用“首次”“最早”“都基于”等强断言时必须有直接依据，否则改写为具体事实表述。方法对比时区分训练与推理、局部部件与整套系统，影响判断的实验条件和局限直接在对应页面说明。

## 时间分配

先按整场时长与主题主线分配各部分权重，再按解释难度确定页数和篇幅，估算时计入读图、演示、停顿和互动。依据已有试讲节奏估算时长，没有试讲数据时注明为预估时间。

时间紧张时，优先删去偏离主题主线的旁支材料、重复结论和可选扩展；如果固定内容与固定时长确实冲突，明确列出建议取舍的部分或案例。

## 检查内容方案

分别在第二阶段与第三阶段收尾时执行对应检查：

- **第二阶段（简要大纲自检，交付用户确认前）**：
  - 通读主题思路与各部分逻辑推进，确认学术故事紧扣同一条主线，没有跑偏支线或为凑板块硬搭的空页；
  - 核查章节划分、总页数与场景及第一阶段确认的基本要求一致，前置概念先于依赖它的页面出现，开场立下的核心命题或悬念在后文得到实质回应；
  - 复查结构独立性，确认章节与页序源自当前课题自身的讲述逻辑，而非照搬参考模板或示例 PPT 的既有骨架。
- **第三阶段（逐页详细设计自检，开始制作 PPT 前）**：
  - 核查每页的排版布局、载体选择与文字篇幅是否契合目标模板与现场扫读需求，没有大段文字堆砌或版面失衡；
  - 核查展示文字、图表、公式与按需脚注均已落实对应规范，且与原始材料事实一致；
  - 顺读相邻页面与连续页组，确认概念衔接、术语称谓、前后呼应与版式节奏自然连贯。

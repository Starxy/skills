# 修改与交付

## 找准版本与范围

分别确定最新指定的内容、样式参考、允许修改的对象和正式文件位置。新内容版本继续继承未被撤销的字体、脚注、标点、备注等约定；文件修改时间不能替代用户的版本指定。

修改前读取目标文件的当前状态。页序已经变化时，用标题和内容确认目标，不直接套用旧页码。沿用生成脚本或模板时检查是否带回已删除的案例、旧标题或旧页序。

将反馈落实在相应层级，并检查授权范围内的同类对象。一次只改脚注、备注或 Markdown 时，修改限定在该对象；需要超出范围才能解决的问题提出具体建议。

## 选择实际制作方式

根据当前环境和文件选择已有演示文稿工具、原生应用或文件处理库。先确认它能够读取与保存所需内容，尤其是备注、公式、媒体和用户已有的格式；读取提取文本时，同时查看需要判断版面的页面。

在用户已有文件上修改时，优先保留其原有对象和格式。选择会重建或丢失复杂元素的方式前，先处理实际兼容问题；不能以成功生成另一个文件代替保留已确认内容。

## 正式文件与关联材料

保留约定的正式文件名和一个清楚的交付入口。需要恢复能力时保留修改前文件或使用已有版本记录，避免堆积多个同级“最终版”。备份放在项目约定位置。

仅在本次任务需要且已获授权时同步页码、大纲、独立稿、章节文件、总稿和相关链接。页序变化后，核对受影响内容的标题、前后引用、转场和指图位置。

文件被占用时另存可用结果，明确它是临时文件及尚未完成的回填。占用解除后先检查正式文件是否又有手改，再合入本次改动并完成链接与版本收尾。

长课件按编辑需要拆章，汇报需要总稿时再合并。PDF、打印用 Word 和其他派生物按用户用途提供；为内部渲染产生的临时文件无需一并交付。

## 按变化检查最终成果

先检查受本次修改影响的内容关系，再检查文件与呈现。选择下面适用的检查，已经有效且未受变化影响的结果可以复用。

| 本次变化 | 应检查的实际结果 |
| --- | --- |
| 新建整套 PPT、重构整章 | 通读整场或整章的主线与页组关系，渲染全部新建或重构页面，核对相关备注与来源 |
| 单页内容或版式 | 读取与渲染修改页；检查受影响的相邻页、转场与指图内容 |
| 全局样式或母版 | 查看所有受该样式影响的页面，检查字体、图例、脚注和章节页一致性 |
| 仅修改或清理备注 | 重新读取范围内每页的实际备注，检查文本、段落间距、空行和超链接；核对页面对象与页序未变 |
| 仅修改独立讲稿 | 连读修改页组，核对页码、标题与来源安排；确认未写入其他文件 |
| 页序、拆章或合并 | 核对实际页序、编号、前后引用、跨章承接及媒体和备注是否随页保留 |
| 图片、公式或视频 | 查看清晰度、裁切和符号；视频在可用播放器中检查播放及片段边界 |

PPT 版面检查要覆盖遮挡、溢出、图内字过小、异常断行、公式显示和字体替换。检查最终保存的文件，不能只看制作代码或中间预览。

PPT 备注检查读取实际备注正文和格式，注意格式可能由主题或母版继承；必要时显式设定段前段后间距并重新保存。核对仅为引用用途的超链接已经移除。只扫描可见文字无法确认间距和链接状态。

修正发现的问题后，复查对应内容和受影响对象；无新变化、失败或未解问题时结束检查。

## 交付与受阻处理

交付时给出正式文件入口，说明本次改动、实际检查以及影响后续使用的缺口。只完成内容设计时称为方案；缺少渲染器时说明尚未验证版面；视频未实际播放时说明未验证播放。

工具受限时继续完成不依赖该工具的部分。原图无法获取可给出准确来源与待补位置，文件无法编辑可给出可直接采用的内容；明确哪些工作仍未写入文件，避免把临时结果称为最终成品。

## 继承反馈

收到纠正后，判断它的触发场景、应采取的行为、完成证据和适用范围。更新本次任务的相关内容；项目约定允许维护规范时，在原规则位置修订并移除冲突条款。

把一次开场方案、某章四页限制、某场每页两分钟等保留为对应任务的选择。将可复用要求迁移到其他任务时保留其条件，避免把历史取舍扩大为所有 PPT 的固定格式。

# 学术蓝默认模板

本文件完整定义学术蓝的样式、版式与使用约束，仅凭本文件即可制作页面，无需读取或复制 PPTX。用户明确指定的样式优先；修改既有 PPT 时保留其已确认样式，除非本次要求更换模板。

[PPTX 示例](../assets/academic-blue-template.pptx)与[版式预览](../assets/academic-blue-preview.png)仅用于理解可选的呈现方式，不是绝对标准。它们的坐标、比例、页数、页序、章节数、图表形式和要点数量均不构成约束；示例与本文件不一致时按本文件执行。根据实际内容选择或新建版式，不要求先复制参考页，也不要求与示例逐页一致。

## 配色与页面结构

以整宽蓝色章节栏、左对齐的蓝色页标题和白底黑字内容区构成整套样式。章节栏内居中放章节编号与名称，页标题说明本页的具体主题；两者不重复同一句话。正文用黑色粗体小标题和短段落组织解释，为原文图表、科学插画、公式和流程分配足够面积，不将每段文字装进蓝色标题框。

| 项目 | 设置 |
| --- | --- |
| 画布 | 默认 16:9，13.33 × 7.5 英寸；用户指定比例时随之调整 |
| 蓝色背景 | 章节栏、封面与章节页色带、表头及确需蓝底的标签统一使用 `#245A8C`，配白色文字 |
| 蓝色文字 | `#1F4E79` 用于页标题、目录编号及少量层级标题；不用蓝色贯穿正文 |
| 背景与细线 | 白底；需要区分区域或表格行时可用浅灰蓝 `#EFF4F9`，细线用 `#C9D9E8`；说明条按内容需要添加 |
| 正文与次要文字 | 主要文字 `#000000`，包括段落、小标题、数据与公式；来源、页码和次要图注用 `#666666` |
| 文字强调 | 红色 `#C00000` 仅用于少量确需突出的词语、条件、差异或数字；不整段标红，不另设绿色正文强调方案 |
| 内容页标题区 | 顶部蓝栏内居中放白色粗体章节名；其下蓝色页标题左对齐。需要补充对象或条件时可有一行简短副标题；不默认添加副标题或标题下划线 |
| 分组与流程 | 优先用间距、黑色粗体小标题和必要细线分组。节点可用直角框或浅色区域，箭头明确连接实际对象；只有需要突出节点层级时使用蓝底标题条 |
| 表格 | `#245A8C` 表头配白色粗体字，主体黑字、细灰蓝网格；首列可加粗，说明文字左对齐，短标签和数字按读数需要排列。行较密时可用浅灰蓝交替底色辅助逐行阅读 |
| 页脚 | 右下角轻量灰色页码；有实际引用时另设来源区域，不重复顶部章节名，也不创建通用补充说明框 |
| 机构标识 | 按用户材料和用途添加，保持原始比例；不在每页重复大面积校徽或水印 |

同层标题、图例、注释和页码保持一致。按默认画布，章节栏高约 0.65–0.7 英寸；页标题位于距上边缘约 0.95–1.5 英寸，正文从约 1.9–2.1 英寸开始。左右正文边距约 0.6 英寸，双栏间距约 0.3–0.5 英寸，页码位于右下角约 7.2 英寸处。表格与分组细线约 0.6–1 pt。

这些数值是排版起点，可根据标题长度、图表形状和内容调整。页标题较长时先精简表述，必要时增加标题区高度并下移正文；短报告没有章节层级时，顶部蓝栏只放报告或主题名，避免另造无意义的章节。内容与页脚之间留出间距，图注靠近对应图表。

## 字体与文字排版

| 字符与对象 | 字体 |
| --- | --- |
| 中文汉字与中文标点 | 微软雅黑（Microsoft YaHei） |
| 英文字母、数字与符号 | Times New Roman，包括英文缩写、页码、坐标刻度、单位、希腊字母和数学符号 |
| 中英文混排 | 在同一文本框中按字符分别应用以上字体；不能只设置整个文本框的一个字体 |

将主题或默认文本样式中的东亚字体设为微软雅黑、西文字体设为 Times New Roman，并检查标题、正文、表格、图表轴、图例、数据标签、页码、图注、脚注和新增标注。指定字体不可用时说明缺失，不静默替换成另一套字体。原文图片和截图内部的文字保持原貌；新增文字及自制内容执行本节要求。

字号可从封面 40–44 pt、顶部章节名 28–30 pt、页标题 28–30 pt、段落小标题 20–22 pt、正文 18–22 pt、表格正文 16–20 pt、图注 13–16 pt、来源与页码 10–12 pt 起步。封面、章节栏、页标题与段落小标题使用粗体；正文以常规字重为主，段落小标题默认黑色。根据内容与投影可读性调整，内容放不下时先删去重复、调整分组和版式或拆页，避免只靠缩小字体容纳文字。短语和完整语句保持自然断行。

公式规范排版上下标、分式、括号和符号，变量解释与必要条件放在同页或紧邻位置。自制公式尽量可编辑，英文、数字和数学符号使用 Times New Roman；工具无法保留所需公式或字体时，采用清晰的矢量或高分辨率输出并保留源式，交付时说明具体限制。

## 版式选择

以下描述是可独立实现的版式选项。根据本页内容安排元素与面积，可组合、调整或采用其他布局；不要求每类页面都出现。

| 页面用途 | 布局与内容安排 |
| --- | --- |
| 封面 | 白底，在页面中上部设置整宽深蓝色带，居中放一至两行白色粗体题目。色带上方左侧、下方右侧各有一段短蓝线；报告人、主题、单位和日期在下方居中分行。字段按用途增减，不固定保留导师或机构标识 |
| 目录 | 顶部蓝栏左侧放白字“目录”，下方用蓝色编号、黑色粗体章节名组成列表，可在章节名下补充具体内容范围，右侧列起始页码；条目间用浅蓝细线分隔。章节数量由实际内容决定 |
| 章节页 | 延续封面的白底、整宽蓝色带和短蓝线，色带中居中放章节编号与大标题；副标题仅在提供额外信息时保留 |
| 单栏正文 | 沿用双层标题区，用黑色粗体小标题、短段落和间距组织信息；必要定义直接放在对应位置，不默认套说明框 |
| 图文并排与双栏对照 | 主图可占约半页至三分之二宽度，另一侧用黑色小标题和段落解释对象、操作或结果；也可反向安排。对照内容采用共同维度，按信息量分配宽度，不为对称补写内容 |
| 技术路线 | 按实际步骤、并行分支和反馈关系排列节点；用黑色标签、浅色节点及蓝色箭头区分层级。箭头标签标明传递内容，折线避开文字；节点数量、形状和走向由研究决定 |
| 公式与符号 | 给主要公式足够面积，附近列出符号、单位与条件；长公式按解释步骤分组或拆页 |
| 单图或多图 | 单图可占据主要内容区，不必加外框或蓝色小标题条；多图按比较关系排列并添加必要面板标记。可比较的图保持一致的单位和适当的坐标范围，各自图注靠近对应图 |
| 数据表格与问题对应 | 用全宽表格展示问题、方法、验证方式等对应关系，说明较长的列分配更多宽度。保留表头、单位与必要注释，行列数量由数据决定；已有论文表格优先使用原表或截图，自制表格保持可编辑 |
| 任务说明 | 上部用黑色粗体标签与短段落放人员、研究目标或输入条件；下部用表格呈现任务、数量、测量内容或交付结果，避免让装饰标签挤占说明空间 |
| 汇总与资源安排 | 上方按需保留一条目标说明，下方并列两张具有不同用途的表格，例如人员安排与数据需求；各表按信息量确定列宽和行高，不强制相同条目数 |
| 相关研究 | 按研究问题选择共同的比较维度，用原文图表、图文并排或文献比较表展示；只列实际核对过的文献 |
| 讨论与局限 | 在相应结果附近或专门页面说明解释、适用条件和具体限制；并列内容可分栏，不为保持对称补写文字 |
| 研究计划 | 将任务与起止时间对应，可用时间表或进度条；阶段成果按实际计划设置 |
| 总结与展望 | 集中呈现研究结果支持的独立结论、贡献和后续问题；条目按实际内容增减 |
| 结束页 | 延续封面的整宽深蓝色带与居中文字，按场合保留致谢、讨论邀请或联系方式 |

## 原文图表与自制内容

展示已有图片、论文或已有工作的内容时，尽量直接使用对应原图、原表或清晰截图。保留原始比例、配色、图内字体、表头、图例、坐标、单位和影响解释的条件，不为套用学术蓝外观而重绘。新增标题、图注或中文标注放在素材周围，避免遮挡原始信息。

原图太小或信息过密时，优先裁切、放大、分步展示或增加必要标注；这些方式仍不能清楚展示、原素材无法获得，或本次需要重新组织比较、教学拆解、编辑数据及用户明确要求重绘时，再制作对应图表。重制时核对数据和关系，将依据保留在来源或备课资料中。通用的可编辑性要求不意味着必须重制原文图表。

标题、正文、新增标注和自制图表尽量保持可编辑；原图、原表截图可以作为图片嵌入。精确数据、实验结果和方法关系采用已有材料或按实际数据绘制，生成式图片不能充当研究结果或论文截图。

需要自制科学插画解释场景、对象或概念时，使用白底、清楚轮廓、柔和明暗和低饱和配色，让人物、设备、组织或研究材料具有可辨认的形态。蓝色、灰色为主，可用少量淡紫、青色等区分对象；保持专业对象的结构与关系准确。图内避免大段文字，术语、变量和精确标签用可编辑文字另行添加。插画说明具体内容，不以装饰性的机器人、发光大脑或无关图标替代研究对象；已有原图不受这套插画配色约束。

方法页应让听众读出输入、关键操作与输出，结果页保留比较条件和支持判断的观察。图文互补：图呈现对象或关系，旁文补充解释；增加内容时补足必要机制、数据或例子，不把抽象词堆成条目，也不把整段讲稿搬上页面。

## 可见文字、备注与引用

- 正文使用正式、客观、简洁的书面表达；每个正文文本框提供事实、概念、方法、结果或必要关系。口语化讲解、转场和补充说明放入演讲者备注；无信息增量的文字直接删除。
- 标题可为主题、问题或有研究结果支持的结论，不强制结论式标题。删除自我辩护、假想质疑与回应，以及描述制作意图或检查过程的文字。
- 不默认添加页底总结、Key Takeaway 或结论框。只有需要强调且未在本页重复表达的独立研究结论才使用结论区域；不为填满页面补写总结或解释。
- 必要的方法条件、研究局限和不确定性在相关方法、结果或局限性页面准确表达。图例、单位、变量和必要条件就近标明，不能仅放在备注中。
- 页面短标题和正文段末不加句号；小数、缩写和公式中的点正常保留。逐字稿使用正常标点。
- 有实际引用时，来源简写采用 `机构，研究者，论文名（全称或简称），正式期刊／会议或资料类型及年份`。优先使用正式发表版本；预印本、讲义和演示按实际类型标识，不补造缺失信息。
- 页脚保留必要来源和页码；详细网址、原文图表编号与定位信息放入备课资料。图注与技术注释随对应对象保留，不将它们当作冗余页脚删除。

可选 PPTX 示例中的方括号文字、图形占位、数值及备注仅用于示意。若采用这些对象，正式汇报交付前替换或删除相关占位、示例数据与使用说明，并更新章节名、页码和备注。用户只要求参考模板时可以保留这些示意内容；不把示例数值当作研究结果。

## 完成检查

制作前核对大纲中的各页内容、素材及布局是否服务于本次讲述。保存后逐页查看全部可见文字与实际布局，检查信息增量、原图完整性、字体、字号、换行、遮挡、溢出、图表单位和必要条件；混排文字同时检查中文与英文、数字、符号的字体。涉及图表重制时对照来源核对数值与关系。

发现问题直接修改对应对象，重新保存并复查受影响页面后交付。示例 PPTX 原有的显示效果、文本提取结果或文件生成成功，均不能替代对本次文件的实际页面检查；缺少渲染、编辑或播放能力时说明具体未检查项目。

# 学术蓝默认模板

使用默认样式制作页面时，查看[版式预览](../assets/academic-blue-preview.png)，并从[可编辑 PPTX](../assets/academic-blue-template.pptx)选取相应参考页。模板选择与既有文件的样式保留遵循 [SKILL.md](../SKILL.md#确定本次任务)。

## 使用模板文件

复制需要的参考页后替换内容，保留其蓝色层级、标题位置、字体和留白。工具无法直接保留 PPTX 对象时，按下面参数重建，并与参考页比较实际渲染效果。参考文件只提供可选版式，不限定整场页数、章节数、要点数量或页面顺序。

| 参考页 | 用途 |
| --- | --- |
| 1 | 封面：机构信息、横向蓝色题目区、报告人信息 |
| 2 | 目录：左侧蓝色标题区、右侧编号章节列表 |
| 3 | 章节页：章节编号、标题与可选副标题 |
| 4 | 单栏正文：按小标题组织短段落 |
| 5 | 左文右图：研究问题与框架图 |
| 6 | 技术路线：分阶段流程及对应动作 |
| 7 | 公式与符号：公式、变量解释及必要条件 |
| 8–9 | 单图展示、双图比较：可编辑折线图与柱形图 |
| 10 | 数据表格：原生表格、单位与技术注释 |
| 11 | 四图组合：图组、面板标记与各自图注 |
| 12 | 相关研究：文献比较表与引用位置 |
| 13 | 讨论与局限：结果解释及具体适用条件 |
| 14 | 研究计划：任务、时段与可编辑进度条 |
| 15 | 总结与展望：研究结论、贡献及后续工作 |
| 16 | 结束页：致谢与可选联系信息 |

模板的方括号文字、图形占位及示例数值用于说明填写位置。制作正式汇报时全部替换或删除，并更新标题、章节名、页码和备注；用户只要求空白或参考模板时可以保留。图表替换数据后同步系列名、坐标、单位和图注，不把示例值当作研究结果。第 7 页公式是可编辑数学字体文本，复杂公式按[公式与可编辑性](visual-design.md#公式与可编辑性)处理。

每页备注说明该版式的使用方式。用于实际汇报时，按本次任务改写为演讲者备注或删除；不把模板使用说明当作逐字稿交付。

## 视觉参数

| 项目 | 默认设置 |
| --- | --- |
| 画布 | 16:9，13.33 × 7.5 英寸 |
| 主色与辅助色 | 深蓝 `#1F4E79`；中蓝 `#457BA5`；浅蓝图表系列 `#93B4CF` |
| 背景与分区 | 白底；浅色内容区 `#F4F7FA`；细分隔线 `#CDDBE7` |
| 文字颜色 | 主要文字 `#243447`；次要文字 `#5D6B79`；标题用深蓝 |
| 字体 | 中文与常规正文用微软雅黑；英文编号可用 Arial；数学符号用 Cambria Math。字体不可用时选择可用的中文无衬线字体并检查换行与符号 |
| 字号 | 封面 40–44 pt；页标题约 28.5–30 pt；小标题 20–24 pt；正文 18–22 pt；图注 14–16 pt；页码约 11 pt。按内容与投影可读性调整 |
| 标题区 | 白底深蓝标题，左侧窄蓝色标记，标题下方细蓝线；不使用浅灰色标题条 |
| 间距 | 左右边距约 0.5–0.67 英寸；正文起点约距上边缘 1.5 英寸；内容与页脚之间保留间距 |
| 封面与章节 | 大面积横向蓝色标题区，配白色文字；封面报告人信息独立放在下方白色区域 |
| 表格与流程 | 深蓝表头、浅色交替行；流程节点采用简洁矩形与方向明确的箭头，颜色区分阶段或对象 |
| 页脚 | 轻量页码，章节名按需要保留；有实际引用时再创建来源区域，不保留无内容的注释框 |

正文保持深色，蓝色主要用于标题、结构和图表系列。机构标识按用户材料和用途添加，保持原始比例；不在每页重复大面积校徽或水印。其余页面空间优先分配给图表、必要文字或留白。

## 标点与引用

- 页面短标题和正文段末不加句号；小数、缩写和公式中的点正常保留。逐字稿使用正常标点。
- 有实际引用时，来源简写采用 `机构，研究者，论文名（全称或简称），正式期刊／会议或资料类型及年份`。有正式发表版本时优先使用；预印本、讲义和演示按实际类型标识，不补造发表渠道。
- 来源脚注省去图号、表格行号、长段解释和网址；这些定位信息放入独立备课资料。影响读图的指标、单位和条件放在图旁。

标题、正文、结论区域和必要注释遵循[页面正文与讲稿](../SKILL.md#页面正文与讲稿)。用[实际版面检查](visual-design.md#检查实际版面)核对替换后的文件，不能只以模板原有页面的显示结果判断新内容。

# 学术蓝默认模板

本文件专门定义**学术蓝默认模板**的配色、字体、标题区、无框开放分层排版、版式细则与组会示例说明，供以下两种情况读取使用：
1. 新建 PPT 时，用户未提供自定义模板、也未指定其他视觉风格；
2. 修改既有 PPT 时，用户明确要求按照本 skill 默认风格（学术蓝风格）对原 PPT 进行重构或美化。

若用户提供了自有模板，或要求在不换风格的前提下局部修改既有 PPT，则按其模板样式执行，无需套用本文件中的具体色值与版式参数。

[PPTX 示例](../assets/academic-blue-template.pptx)与[版式预览](../assets/academic-blue-preview.png)是一份以 *Attention Is All You Need*（`arXiv:1706.03762`）为主题的完整组会精读示例，用来直观展示学术蓝风格在实际汇报中的视觉效果。制作新 PPT 时**参考的是这套配色、标题样式、排版习惯与文字规范，而不是示例的章节划分、页数、讲法或固定逻辑**；具体内容和版式由当前汇报的大纲决定，不要把它当作固定填空模板来套用，也不要复刻示例中的页面组织序列与版式配比。

## 配色与页面结构

保留学术蓝低调简约、偏低亮度的扁平化配色骨架，以及封面、目录和章节过渡页版式；内容页遵循“表不如图、字不如表”优先级，采用“顶部蓝色章节栏 + 居中重点句标题及下划线 + 无外框开放白底分层文字/图表/无框分栏 + 提纲挈领、分层次突出关键词的书面表述（无中文句号、问题不用问号） + 规范 LaTeX 数学公式”的组织方式；文字严格限定深蓝、黑、学术红三色（灰色仅用于脚注与页码），低饱和科研辅色仅用于图表与插画，只在需要交代他人出处时添加参考文献脚注。

| 项目 | 设置 |
| --- | --- |
| 画布 | 默认 16:9，13.33 × 7.5 英寸；用户指定比例时随之调整 |
| 蓝色主骨架 | 封面色带、章节页色带、顶部章节栏、目录编号方块与表头统一用 `#245A8C` 配白字；`#1F4E79` 用于居中页标题、标题下划线、目录章节名、栏标题与小节标题、前置关键词、流程箭头及少量必要高亮框边框 |
| 浅灰蓝与细线 | 白底；单页最多 1 条的轻量核心问题/定义条、信息表首行或少量流程节点底色用 `#EFF4F9` / `#E7EFFA`；文字分组间分隔横线、无框多栏分隔竖线与表格网格线用 `#C9D9E8` |
| 文字配色（仅三色 + 脚注灰） | 页面文字严格只采用三种颜色：**主色深蓝 `#1F4E79`**（标题、小标题、关键词标签）、**黑色 `#000000`**（正文、表格文字与公式主体）、**学术红 `#C82423` / `#C00000`**（仅用于少量核心结论词、痛点或关键数值强调，不整段标红）；**灰色 `#666666` 只作为页底参考文献脚注及右下角页码出现**。**禁止在文字内容、并列小标题或分栏顶条上使用绿色、粉色、紫色等多种对比颜色** |
| 图表与插画辅色（仅限图件） | 遵循低调简约、亮度偏低、扁平化的学术风格，全篇图件配色方式一致；以下顶刊科研互补色**只约束自绘数据图表与生成的学术插画，不用于页面正文文字或标题色条**：<br>· **暖红 / 珊瑚系**：`#C82423` / `#D8383A` / `#F8AC8C` / `#FF8884` 及浅粉区 `#F7E1ED`（异常、掩码、对比系列或峰值高亮）<br>· **鼠尾草绿**：`#96C37D`（正常对照、正向通路或并行系列）<br>· **暖琥珀黄**：`#F3D266`（信号节点、预热区间或中间高亮）<br>· **次蓝与灰紫**：`#2F7FC1` / `#9AC9DB` / `#A9B8C6`（多组蓝灰层次）、`#C497B2`（跨模块或次要对照类别） |
| 内容页标题区 | 顶部 `#245A8C` 整宽章节栏内**左对齐**放白色粗体章节名；其下白底居中放 `#1F4E79` 粗体一句话核心标题，标题正下方一道 `#1F4E79` 居中细线 |
| 核心问题或定义条 | 页面开篇需要交代核心定义或总领问题时，在标题下划线下方放至多 1 条轻量说明条：可用 `#EFF4F9` 底加 `#1F4E79` 细边框，或左侧 `#245A8C` 色块配白字短标签、右侧浅底细框放陈述句形式的核心问题或定义（不使用问号）。无需时省略 |
| 主要文字排版与无框分栏（首选） | **主要文字内容默认采用无外框开放白底分层排版**（如示例第 8 页）：直接排布在干净白底上，用 `#1F4E79` 粗体小标题引出组块，组内用 `#1F4E79` 加粗前置关键词配黑色正文，各要点组或并列栏之间仅用 `#C9D9E8` 细横线/细竖线与留白分隔。**严格克制外框数量**：单页禁止堆砌多个“外框 + 蓝顶条 + 内文本”的卡片盒子，也不得在表格、图表或插画外再包外框（杜绝框套表、框套图与双层蓝条）；仅在简单流程图确需可编辑节点时使用少量轻量 `#EFF4F9` 节点框配 `#1F4E79` 箭头 |
| 大图、图表与宽表 | 原图、生成的科学插画、原生图表、全宽数据表与长公式均直接在白底展开，不套外框或卡片容器 |
| 表格 | `#245A8C` 表头配白色粗体字，主体白底黑字配 `#C9D9E8` 细网格；首列可加粗，长句说明左对齐，短标签和数字按阅读习惯对齐。任务或汇总页上方可用双列信息表（左列 `#1F4E79` 粗体标签，首行可配 `#EFF4F9` 底色，右列完整长句） |
| 页码与文献脚注 | 章节页与内容页右下角放轻量灰色页码（封面、目录与结束页不放页码）；**默认不在页面底部加参考文献脚注**。仅在引用他人论文原图、原表、数据或观点且需交代出处时，在页底左下角加一行 `#666666` 文献来源 |
| 机构标识 | 按用户材料和场合保留原始比例使用，不在每页重复大面积校徽或水印 |

按默认 16:9 画布起步：顶部章节栏高约 `0.75–0.79` 英寸，左对齐章节名距左约 `0.35` 英寸；居中重点句标题位于 `y ≈ 1.00–1.07` 英寸，居中下划线位于 `y ≈ 1.60–1.65` 英寸（宽约 `11.1–12.0` 英寸，粗细 `1–1.5 pt`）；正文从 `y ≈ 1.88–1.95` 英寸开始，左右边距约 `0.58–0.65` 英寸，栏间间距约 `0.25–0.35` 英寸，页码位于右下角 `y ≈ 7.15` 英寸。标题较长时先精简为一句清楚的话，确实需要换行时相应下移下划线和正文起点。

## 字体、字号、标点与数学公式

| 字符与对象 | 字体与排版规范 |
| --- | --- |
| 中文汉字与中文标点 | 微软雅黑（Microsoft YaHei） |
| 英文字母、数字与普通符号 | Times New Roman，包括英文缩写、页码、坐标刻度与单位 |
| 中英文混排 | 在同一文本框中按字符分别设置以上字体 |
| 独立公式与行内数学符号 | 采用**专业的 LaTeX 数学公式形式**（生成原生公式对象 `<a14:m><m:oMath>` 或高分辨率 LaTeX 公式渲染，规范排版斜体变量、正体算子、上下标、分式与根号，不使用 `d_model`、`h_(t-1)`、`10000^(2i/d_model)` 等纯文本近似） |

将主题或默认字体设为东亚“微软雅黑”、西文“Times New Roman”，检查自制文本、表格、原生图表坐标轴与图例、页码、图注和脚注；指定字体不可用时说明情况。原论文图片和截图内部文字保持原貌。

推荐起步字号：封面大标题 `40–44 pt`、章节页大标题 `40 pt`、顶部章节名 `28–32 pt`、居中页标题 `25–28 pt`、栏标题与小节标题 `18–21 pt`、前置重点标签 `15–18 pt`、正文与要点说明 `16.5–20 pt`、表格正文 `14.5–18 pt`、图注 `13–15 pt`、页码与按需文献脚注 `10–12 pt`。封面、章节栏、页标题、栏标题及段落小标题使用粗体，正文用常规字重。内容区关键数字与规模指标沿用正文或小标题字号，以加粗或少量学术红 `#C82423` 强调，禁止单独放大至 `30 pt` 以上做成商业 KPI 大字卡。空间不足时先精简重复词句、改用图表或拆页，避免靠不断缩小字号硬塞内容。

**默认文字间距与层次表达（详见[展示文字写作风格与反防御要求](writing-style.md#2-句式与标点硬性约束)）：**
- **默认间距**：正文与各栏段落默认采用 **行间距 `1.2` 倍、字间距 `1 pt`（OOXML `<a:rPr spc="100"/>`）、段落间段前 `6 pt`**（首段不顶空；紧凑表格、图注和页脚按空间适度收紧）。
- **提纲挈领与层次关键词**：优先“表不如图、字不如表”；文字区域采用无外框开放白底分层排布，以正式、前后一致的书面短句配加粗小标题/前置标签突出关键词，不同组块间用 `#C9D9E8` 细线和留白分隔，切忌大段罗列文字与多盒堆砌。
- **全篇 PPT 禁止出现任何中文句号（`。`）**：标题、核心问题条、分层正文、表格单元格、图注及文献脚注末尾一律不加中文句号 `。`，句内分句用逗号 `，`、分号 `；` 或顿号 `、` 连接；英文小数点、缩写点与数学公式中的点号正常保留。
- **科学问题与核心问题禁止出现问号（`？` / `?`）**：统一使用陈述句表述研究问题与核心矛盾。

## 可选视觉版式与图文混排模式

以下版式属于**按内容关系自由挑选和组合的视觉模式构件**，不绑定具体页面主题（如表达“科学问题”时不固定配表格，可根据实际材料改用无框文字层次、顶部 1 条轻量核心问题配下方无框子问题，或核心问题配学术插画；表达“研究框架与机制流向”时，按复杂程度灵活选用轻量可编辑节点或生成直观学术插画），亦不要求全部版式在单份 PPT 中强行出现：

| 版式构件 | 空间组织与典型适用方式 |
| --- | --- |
| 封面 | 白底，中上部整宽 `#245A8C` 色带配一至两行居中白色粗体题目；色带左上与右下各配一段短蓝线；下方白色区域置入低不透明度、与白底自然融合的山东大学中心校区正门底图，其上居中分行排列作者、来源、主题和场合（文本框设为无填充）。字段按场合增减 |
| 目录 | 顶部 `#245A8C` 栏左侧白字“目录”；下方白底区域**整体水平与垂直居中**排列章节列表：每项由左侧 `#245A8C` 正方形深蓝方块配居中白色粗体编号（如 `01`、`02`）与右侧 `#1F4E79` 粗体章节名组成（各行左对齐），不显示章节页码与页底页码，不加分隔横线，也不在标题下方附加一句话范围说明 |
| 章节过渡页（每章必配） | **每个章节起始处均放置独立的章节过渡页**（即使某章页数较少也完整保留）：延续封面白底、整宽 `#245A8C` 色带与两段短蓝线，色带中居中放章节编号与名称，下方保持干净留白（默认不附加本节范围说明副标题），右下角标页码 |
| 总览大图与无框分点定位（建议前置） | 当后文将分点介绍“研究内容 / 研究方法 / 技术路线 一、二、三”时，建议在其前方设一页总览图：中部或上部白底展开全局结构插画或可编辑路线图，下方用无框三栏分层文字（深蓝栏标题 + 短横线/细箭头 + 关键词要点）交代各分点定位与关系 |
| 左图右文 / 右图左文（主要文字页首选） | 依据视觉焦点灵活切换图片在左或在右：一侧在白底直接展开论文原图、高信息量图件或白底学术插画（不套外框），另一侧采用**无外框开放分层文字**（`#1F4E79` 粗体小标题 + 前置关键词配黑色正文 + `#C9D9E8` 细横线分隔，如示例第 8 页）；需要交代总领核心问题时，上方至多配 1 条轻量 `#EFF4F9` 问题条，下方子问题仍无框排布 |
| 双栏无框图文 / 双栏文字对比 | 左右两栏直接在白底并排，中间用留白或一条 `#C9D9E8` 细竖线分隔；栏顶放 `#1F4E79` 粗体栏标题配细下划线，下方直接展开原图、紧凑表格、原生图表或分层文字（不套卡片外框与双层蓝条） |
| 三栏无框图文混排 | 三栏等宽直接白底并排，栏间以 `#C9D9E8` 细竖线与留白分隔（栏宽约 `3.84` 英寸、间距 `0.30` 英寸）；栏顶用 `#1F4E79` 编号小标题，上半部分嵌入轻量示意图或热图，中段细横线分隔，下半部分配分层要点 |
| 四栏无框图文混排 | 四栏等宽直接白底并排，栏间以 `#C9D9E8` 细竖线与留白分隔（栏宽约 `2.85` 英寸、间距 `0.24` 英寸）；适用于四项训练设置、四类策略模块、四维对比或四步特征分解；上方放小型统计/机制简图，中段细横线，下方配紧致分层要点与关键数字 |
| 流程框架（轻量节点 vs 生成插画） | 节点少、边界明确且需频繁改字时，采用少量 `#EFF4F9` 轻量节点框配 `#1F4E79` 箭头与短标签；多模块跨层耦合、空间或机理难以用简单方框看清时，直接生成学术蓝风格白底插画或使用原论文图 |
| 公式居中 + 全宽参数动机表 | 上方按需配至多 1 条 `#EFF4F9` 核心设定条，中部居中排布专业 LaTeX 数学公式，下方用全宽表格给出组件、参数设置与设计动机 |
| 条件条 + 全宽表 / 键值信息表 | 上方按需配至多 1 条轻量条件条或双列键值信息表（首行 `#EFF4F9` 底、左列 `#1F4E79` 粗体标签），下方接全宽实验数据/消融表；也可仅用无框分层文字而不必强行配表 |
| 结束页 | 延续白底、整宽 `#245A8C` 色带与左上/右下两段短蓝线，色带内居中放白色粗体“敬请批评指正”，下方按场合居中排列作者、汇报日期等内容，不需时保持干净留白 |

## 原文图表、插画与按需脚注

展示已有论文或工作成果时，优先使用原图、原表或清晰截图，保留原始比例、图内字体、坐标、单位和图例，不为套用模板配色而重绘。

展示研究背景、应用情境、生物/工程机理或复杂直观概念时，**不必局限于 PPT 原生形状或简单流程图**，可调用图片生成工具直接生成白底、轮廓清晰的顶刊科研机制图（扁平矢量或 *Nature* 风格学术插画）。**插画与自绘图表不强制压成单调的蓝灰单色**：以学术蓝（`#14517C` / `#245A8C` / `#2F7FC1`）和浅灰蓝（`#E7EFFA` / `#A9B8C6`）定主基调，同时在图件内部按语义搭配 2–3 种柔和的互补辅色（如鼠尾草绿 `#96C37D`、暖琥珀 `#F3D266`、砖红/珊瑚橙 `#D8383A` / `#F8AC8C`、灰紫/淡粉 `#C497B2` / `#F7E1ED`）区分正常与异常、关键信号节点或不同功能模块，保持纯白底与低饱和科研克制感；而页面本身的文字仍严格遵守深蓝、黑、学术红三色（灰仅用于脚注与页码）。这类背景或概念插画旨在辅助直观理解与美化版面，无需为其硬加图注或坐标说明，在逐字稿中也不对其作专门解释。

仅在必要时（如页面直接展示了他人论文原图、原表、实验数据或核心方法观点）在左下角加文献脚注，格式遵循[文献脚注格式与示例](writing-style.md#4-克制总结框与按需添加参考文献脚注)：`研究机构（多个机构用顿号“、”分隔），第一作者姓 等，论文完整标题，发表会议/期刊与年份`（多篇用 `；` 分隔，末尾不加中文句号），例如：
- `南京大学、百度、电子科技大学，Liu 等，ChessArena: A Chess Testbed for Evaluating Strategic Reasoning Capabilities of Large Language Models，ACL 2026`
- `哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model Implicit in a Generative Model，NeurIPS 2024`
- `DeepSeek-AI，Guo 等，DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning，Nature 2025`
- `哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model，NeurIPS 2024；`

页面展示本人工作、整体背景、通用公式推导、流程梳理或总结讨论时，不加文献脚注。

PPTX 示例中的页面内容仅服务于该论文组会演示本身（示例文件未内嵌演讲者备注）；新建或按本模板重构正式汇报时，应依据实际内容和听众重新组织章节与版式。

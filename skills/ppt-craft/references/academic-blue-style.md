# 学术蓝默认模板

本文件专门定义**学术蓝默认模板**的配色、字体、标题区、卡片结构、版式细则与组会示例说明，供以下两种情况读取使用：
1. 新建 PPT 时，用户未提供自定义模板、也未指定其他视觉风格；
2. 修改既有 PPT 时，用户明确要求按照本 skill 默认风格（学术蓝风格）对原 PPT 进行重构或美化。

若用户提供了自有模板，或要求在不换风格的前提下局部修改既有 PPT，则按其模板样式执行，无需套用本文件中的具体色值与版式参数。

[PPTX 示例](../assets/academic-blue-template.pptx)与[版式预览](../assets/academic-blue-preview.png)是一份以 *Attention Is All You Need*（`arXiv:1706.03762`）为主题的完整组会精读示例，用来直观展示学术蓝风格在实际汇报中的视觉效果。制作新 PPT 时**参考的是这套配色、标题样式、排版习惯与文字规范，而不是示例的章节划分、页数、讲法或固定逻辑**；具体内容和版式由当前汇报的大纲决定，不要把它当作固定填空模板来套用，也不要复刻示例中的页面组织序列与版式配比。

## 配色与页面结构

保留学术蓝配色体系，以及封面、目录和章节首页版式；内容页采用“顶部蓝色章节栏 + 居中重点句标题及下划线 + 卡片或清晰分栏 + 完整长句表述（无中文句号、问题不用问号） + 规范 LaTeX 数学公式”的组织方式，只在需要交代他人出处时添加参考文献脚注。

| 项目 | 设置 |
| --- | --- |
| 画布 | 默认 16:9，13.33 × 7.5 英寸；用户指定比例时随之调整 |
| 蓝色背景 | 封面色带、章节页色带、顶部章节栏、卡片标题条、表头及强调标签统一用 `#245A8C`，配白色文字 |
| 强调蓝 | `#1F4E79`，用于内容页居中标题、标题下划线、卡片边框、流程箭头、目录编号及关键小标题 |
| 浅灰蓝与细线 | 白底；高亮定义框、信息表首行或节点底色按需用 `#EFF4F9`，卡片内分隔横线与表格网格线用 `#C9D9E8` |
| 正文与次要文字 | 正文、加粗小标题、数据与公式主体用 `#000000`；页码、次要图注与按需文献脚注用 `#666666` |
| 文字强调 | 红色 `#C00000` 仅用于少量需要突出的关键结论词、问题或核心数字，不整段标红 |
| 内容页标题区 | 顶部 `#245A8C` 整宽章节栏内**左对齐**放白色粗体章节名；其下白底居中放 `#1F4E79` 粗体一句话核心标题，标题正下方一道 `#1F4E79` 居中细线 |
| 核心问题或定义条 | 页面开篇需要交代核心定义或总领问题时，在标题下划线下方放一条整宽说明框：可用 `#EFF4F9` 底加 `#1F4E79` 细边框，或左侧 `#245A8C` 色块配白字短标签、右侧白底细框放陈述句形式的核心问题或定义（不使用问号）。无需时省略 |
| 卡片与流程 | 并列比较、阶段说明或机制展示优先用卡片式结构：`#245A8C` 顶条配居中白色粗体组标题，白色主体配 `1 pt #1F4E79` 细框；卡片内用黑色粗体小标题引出完整长句，同卡内多条之间用 `#C9D9E8` 横线分隔。流程节点可沿用卡片或 `#EFF4F9` 框，用 `#1F4E79` 箭头和短标签连接 |
| 大图与宽表 | 需要给原图、生成的科学插画、全宽数据表或长公式留出最大面积时，可直接在白底展开，不必强套卡片外框 |
| 表格 | `#245A8C` 表头配白色粗体字，主体白底黑字配 `#C9D9E8` 细网格；首列可加粗，长句说明左对齐，短标签和数字按阅读习惯对齐。任务或汇总页上方可用双列信息表（左列 `#1F4E79` 粗体标签，首行可配 `#EFF4F9` 底色，右列完整长句） |
| 页码与文献脚注 | 右下角放轻量灰色页码；**默认不在页面底部加参考文献脚注**。仅在引用他人论文原图、原表、数据或观点且需交代出处时，在页底左下角加一行 `#666666` 文献来源 |
| 机构标识 | 按用户材料和场合保留原始比例使用，不在每页重复大面积校徽或水印 |

按默认 16:9 画布起步：顶部章节栏高约 `0.75–0.79` 英寸，左对齐章节名距左约 `0.35` 英寸；居中重点句标题位于 `y ≈ 1.00–1.07` 英寸，居中下划线位于 `y ≈ 1.60–1.65` 英寸（宽约 `11.1–12.0` 英寸，粗细 `1–1.5 pt`）；正文从 `y ≈ 1.88–1.95` 英寸开始，左右边距约 `0.58–0.65` 英寸，栏间或卡片间距约 `0.25–0.35` 英寸，页码位于右下角 `y ≈ 7.15` 英寸。标题较长时先精简为一句清楚的话，确实需要换行时相应下移下划线和正文起点。

## 字体、字号、标点与数学公式

| 字符与对象 | 字体与排版规范 |
| --- | --- |
| 中文汉字与中文标点 | 微软雅黑（Microsoft YaHei） |
| 英文字母、数字与普通符号 | Times New Roman，包括英文缩写、页码、坐标刻度与单位 |
| 中英文混排 | 在同一文本框中按字符分别设置以上字体 |
| 独立公式与行内数学符号 | 采用**专业的 LaTeX 数学公式形式**（生成原生公式对象 `<a14:m><m:oMath>` 或高分辨率 LaTeX 公式渲染，规范排版斜体变量、正体算子、上下标、分式与根号，不使用 `d_model`、`h_(t-1)`、`10000^(2i/d_model)` 等纯文本近似） |

将主题或默认字体设为东亚“微软雅黑”、西文“Times New Roman”，检查自制文本、表格、原生图表坐标轴与图例、页码、图注和脚注；指定字体不可用时说明情况。原论文图片和截图内部文字保持原貌。

推荐起步字号：封面大标题 `40–44 pt`、章节页大标题 `40 pt`、顶部章节名 `28–32 pt`、居中页标题 `25–28 pt`、卡片标题条 `19–21 pt`、卡片内小标题与重点标签 `19–21 pt`、正文与长句说明 `16.5–20 pt`、表格正文 `14.5–18 pt`、图注 `13–15 pt`、页码与按需文献脚注 `10–12 pt`。封面、章节栏、页标题、卡片标题条及段落小标题使用粗体，正文用常规字重。空间不足时先精简重复词句、调整分栏或拆页，避免靠不断缩小字号硬塞内容。

**长句表述与标点（详见[展示文字写作风格与反防御要求](writing-style.md#2-句式与标点硬性约束)）：**
- 正文段落、卡片内解释和表格说明列采用完整、自洽的书面长句（交代清楚研究对象、作用关系或条件）。
- **全篇 PPT 禁止出现任何中文句号（`。`）**：标题、核心问题框、卡片正文、表格单元格、图注及文献脚注末尾一律不加中文句号 `。`，句内分句用逗号 `，`、分号 `；` 或顿号 `、` 连接；英文小数点、缩写点与数学公式中的点号正常保留。
- **科学问题与核心问题禁止出现问号（`？` / `?`）**：统一使用严谨的陈述句表述研究问题与核心矛盾。

## 可选视觉版式与图文混排模式

以下版式属于**按内容关系自由挑选和组合的视觉模式构件**，不绑定具体页面主题（如表达“科学问题”时不固定配表格，可根据实际材料改用纯文字层次、主问题加两三个子问题分栏，或核心问题配学术插画；表达“研究框架与机制流向”时，按复杂程度灵活选用可编辑 PPT 节点或生成直观学术插画），亦不要求全部版式在单份 PPT 中强行出现：

| 版式构件 | 空间组织与典型适用方式 |
| --- | --- |
| 封面 | 白底，中上部整宽 `#245A8C` 色带配一至两行居中白色粗体题目；色带左上与右下各配一段短蓝线；下方白色区域置入低不透明度、与白底自然融合的山东大学中心校区正门底图，其上居中分行排列作者、来源、主题和场合（文本框设为无填充）。字段按场合增减 |
| 目录 | 顶部 `#245A8C` 栏左侧白字“目录”；下方用 `#1F4E79` 大号编号与黑色粗体章节名组成列表（默认只保留编号、章节标题和右侧各章过渡页起始页码，不在标题下方附加一句话范围说明），条目间以 `#C9D9E8` 细线分隔 |
| 章节过渡页（每章必配） | **每个章节起始处均放置独立的章节过渡页**（即使某章页数较少也完整保留）：延续封面白底、整宽 `#245A8C` 色带与两段短蓝线，色带中居中放章节编号与名称，下方保持干净留白（默认不附加本节范围说明副标题），右下角标页码 |
| 总览大图与分点定位（建议前置） | 当后文将分点介绍“研究内容 / 研究方法 / 技术路线 一、二、三”时，建议在其前方设一页总览图：中部或上部放一张直观展示全局结构的生成插画或可编辑路线图，下方或旁侧配递进标签/卡片交代各分点定位与关系 |
| 左图右文 / 右图左文（多样非对称混排） | 依据视觉焦点灵活切换图片在左或在右：一侧留白展开论文原图、高信息量图件或白底生成学术插画（可放卡片内，也可无框铺开），另一侧放粗体小标题引出的完整长句、主子问题拆解（如上方 1 个主问题框 + 下方 2 个子问题卡片）或分级条目 |
| 双栏图文 / 双栏文字卡片 | 左右双卡片并排，可均采用“上图下长句”（如原图对照）、“纯分层文字对比”（如收益与局限），或左大号核心指标卡片配右原生柱状/折线图表 |
| 无框并列图文对比 | 两张或多张结果图/可视化图件直接白底并排摆放（不套卡片外框），图上配黑色粗体小标题，图下直接承接完整长句观察结论 |
| 三栏卡片图文混排 | 三张等宽卡片并排，适用于三项并行机制、三类问题拆解、三种方法对比或三大技术支柱；卡片上半部分嵌入轻量示意图、矩阵缩略图或生成小插画，下半部分配小标题与完整长句（栏宽约 `3.84` 英寸、间距 `0.30` 英寸） |
| 四栏并行图文混排 | 四张等宽卡片或无框分栏并行（栏宽约 `2.85` 英寸、间距 `0.24` 英寸），适用于四项训练设置、四类策略模块、四维对比或四步特征分解；上方放小型曲线/比例条/机制示意简图，下方配精炼长句与关键数字 |
| 流程框架（可编辑节点 vs 生成插画） | 节点少、边界明确且需频繁改字时，采用 `#245A8C` 顶条卡片或 `#EFF4F9` 节点配合 `#1F4E79` 箭头与短标签；多模块跨层耦合、空间或机理难以用简单方框看清时，直接生成学术蓝风格完整插画或使用原论文图 |
| 公式居中 + 全宽参数动机表 | 上方按需配 `#EFF4F9` 核心设定条，中部居中排布专业 LaTeX 数学公式，下方用全宽表格给出组件、参数设置与设计动机 |
| 条件条 + 全宽表 / 键值信息表 | 上方配条件框或双列键值信息表（首行 `#EFF4F9` 底、左列 `#1F4E79` 粗体标签），下方接全宽实验数据/消融表或双并列表格；注意也可仅用纯文字或双栏卡片而不必强行配表 |
| 结束页 | 延续白底、整宽 `#245A8C` 色带与左上/右下两段短蓝线，色带内居中放白色粗体“敬请批评指正”，下方按场合居中排列作者、汇报日期等内容，不需时保持干净留白 |

## 原文图表、插画与按需脚注

展示已有论文或工作成果时，优先使用原图、原表或清晰截图，保留原始比例、图内字体、坐标、单位和图例，不为套用模板配色而重绘。

展示研究背景、应用情境或复杂直观概念时，**不必局限于 PPT 原生形状或简单流程图**，可调用图片生成工具直接生成白底、轮廓清晰、蓝灰为主（配少量 `#245A8C` / `#1F4E79` / `#EFF4F9` 层次）的学术风格插画。这类背景或概念插画旨在辅助直观理解与美化版面，无需为其硬加图注或坐标说明，在逐字稿中也不对其作专门解释。

仅在必要时（如页面直接展示了他人论文原图、原表、实验数据或核心方法观点）在左下角加文献脚注，格式遵循[文献脚注格式与示例](writing-style.md#4-克制总结框与按需添加参考文献脚注)：`研究机构（多个机构用顿号“、”分隔），第一作者姓 等，论文完整标题，发表会议/期刊与年份`（多篇用 `；` 分隔，末尾不加中文句号），例如：
- `南京大学、百度、电子科技大学，Liu 等，ChessArena: A Chess Testbed for Evaluating Strategic Reasoning Capabilities of Large Language Models，ACL 2026`
- `哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model Implicit in a Generative Model，NeurIPS 2024`
- `DeepSeek-AI，Guo 等，DeepSeek-R1 incentivizes reasoning in LLMs through reinforcement learning，Nature 2025`
- `哈佛大学、MIT、康奈尔大学，Vafa 等，Evaluating the World Model，NeurIPS 2024；`

页面展示本人工作、整体背景、通用公式推导、流程梳理或总结讨论时，不加文献脚注。

PPTX 示例中的页面内容仅服务于该论文组会演示本身（且默认不包含演讲者备注）；新建或按本模板重构正式汇报时，应依据实际内容和听众重新组织章节与版式。

# 学术蓝默认模板

本文件定义学术蓝默认样式、版式与文字规范，直接依据本文件即可制作页面。用户明确指定其他样式时按其要求执行；修改既有 PPT 时保留原有已确认样式。

[PPTX 示例](../assets/academic-blue-template.pptx)与[版式预览](../assets/academic-blue-preview.png)是一份以 *Attention Is All You Need*（`arXiv:1706.03762`）为主题的完整组会精读示例，用来直观展示学术蓝风格在实际汇报中的视觉效果。制作新 PPT 时**参考的是这套配色、标题样式、排版习惯与文字规范，而不是示例的章节划分、页数、讲法或固定逻辑**；具体内容和版式由当前汇报主题决定，不要把它当作固定填空模板来套用。

## 配色与页面结构

保留学术蓝原有配色体系，以及封面、目录和章节首页版式；内容页采用“顶部蓝色章节栏 + 居中重点句标题及下划线 + 卡片或清晰分栏 + 完整长句表述”的组织方式，只在需要交代他人出处时添加参考文献脚注。

| 项目 | 设置 |
| --- | --- |
| 画布 | 默认 16:9，13.33 × 7.5 英寸；用户指定比例时随之调整 |
| 蓝色背景 | 封面色带、章节页色带、顶部章节栏、卡片标题条、表头及强调标签统一用 `#245A8C`，配白色文字 |
| 强调蓝 | `#1F4E79`，用于内容页居中标题、标题下划线、卡片边框、流程箭头、目录编号及关键小标题 |
| 浅灰蓝与细线 | 白底；高亮定义框、信息表首行或节点底色按需用 `#EFF4F9`，卡片内分隔横线与表格网格线用 `#C9D9E8` |
| 正文与次要文字 | 正文、加粗小标题、数据与公式主体用 `#000000`；页码、次要图注与按需文献脚注用 `#666666` |
| 文字强调 | 红色 `#C00000` 仅用于少量需要突出的关键结论词、问题或核心数字，不整段标红 |
| 内容页标题区 | 顶部 `#245A8C` 整宽章节栏内**左对齐**放白色粗体章节名；其下白底居中放 `#1F4E79` 粗体一句话核心标题，标题正下方一道 `#1F4E79` 居中细线 |
| 核心问题或定义条 | 页面开篇需要交代核心定义或总领问题时，在标题下划线下方放一条整宽说明框：可用 `#EFF4F9` 底加 `#1F4E79` 细边框，或左侧 `#245A8C` 色块配白字短标签、右侧白底细框放一两句长句。无需时省略 |
| 卡片与流程 | 并列比较、阶段说明或机制展示优先用卡片式结构：`#245A8C` 顶条配居中白色粗体组标题，白色主体配 `1 pt #1F4E79` 细框；卡片内用黑色粗体小标题引出完整长句，同卡内多条之间用 `#C9D9E8` 横线分隔。流程节点可沿用卡片或 `#EFF4F9` 框，用 `#1F4E79` 箭头和短标签连接 |
| 大图与宽表 | 需要给原图、全宽数据表或长公式留出最大面积时，可直接在白底展开，不必强套卡片外框 |
| 表格 | `#245A8C` 表头配白色粗体字，主体白底黑字配 `#C9D9E8` 细网格；首列可加粗，长句说明左对齐，短标签和数字按阅读习惯对齐。任务或汇总页上方可用双列信息表（左列 `#1F4E79` 粗体标签，首行可配 `#EFF4F9` 底色，右列完整长句） |
| 页码与文献脚注 | 右下角放轻量灰色页码；**默认不在页面底部加参考文献脚注**。仅在引用他人论文原图、原表、数据或观点且需交代出处时，在页底左下角加一行 `#666666` 简写来源 |
| 机构标识 | 按用户材料和场合保留原始比例使用，不在每页重复大面积校徽或水印 |

按默认 16:9 画布起步：顶部章节栏高约 `0.75–0.79` 英寸，左对齐章节名距左约 `0.35` 英寸；居中重点句标题位于 `y ≈ 1.00–1.07` 英寸，居中下划线位于 `y ≈ 1.60–1.65` 英寸（宽约 `11.1–12.0` 英寸，粗细 `1–1.5 pt`）；正文从 `y ≈ 1.88–1.95` 英寸开始，左右边距约 `0.58–0.65` 英寸，栏间或卡片间距约 `0.25–0.35` 英寸，页码位于右下角 `y ≈ 7.15` 英寸。标题较长时先精简为一句清楚的话，确实需要换行时相应下移下划线和正文起点。

## 字体、字号与标点

| 字符与对象 | 字体 |
| --- | --- |
| 中文汉字与中文标点 | 微软雅黑（Microsoft YaHei） |
| 英文字母、数字与符号 | Times New Roman，包括英文缩写、页码、坐标刻度、单位、希腊字母和数学符号 |
| 中英文混排 | 在同一文本框中按字符分别设置以上字体 |

将主题或默认字体设为东亚“微软雅黑”、西文“Times New Roman”，检查自制文本、表格、原生图表坐标轴与图例、页码、图注和脚注；指定字体不可用时说明情况。原论文图片和截图内部文字保持原貌。

推荐起步字号：封面大标题 `40–44 pt`、章节页大标题 `40 pt`、顶部章节名 `28–32 pt`、居中页标题 `26–28 pt`、卡片标题条 `20–21 pt`、卡片内小标题与重点标签 `19–21 pt`、正文与长句说明 `17–21 pt`、表格正文 `16–19 pt`、图注 `13–15 pt`、页码与按需文献脚注 `10–12 pt`。封面、章节栏、页标题、卡片标题条及段落小标题使用粗体，正文用常规字重。空间不足时先精简重复词句、调整分栏或拆页，避免靠不断缩小字号硬塞内容。

**长句表述与标点：**
- 顶部居中页标题、卡片标题条、表头及短词标签末尾不加句号。
- 正文段落、卡片内解释和表格说明列采用完整、自洽的书面长句（一般一至三句，交代对象、关系或条件），使用正常中文标点（包括句末句号 `。`）。小数、缩写和公式中的点正常保留。

公式规范排版上下标、分式、括号和符号，变量含义与条件放在同页表格或紧邻位置。优先采用可编辑公式或清晰文本；工具不支持复杂排版时用高分辨率矢量图或图片并保留源式。

## 常见版式选择

以下版式可按内容自由组合，不要求全部出现：

| 页面用途 | 布局与内容安排 |
| --- | --- |
| 封面（沿用原版式） | 白底，中上部整宽 `#245A8C` 色带配一至两行居中白色粗体题目；色带左上与右下各配一段短蓝线；汇报人、主题、单位和日期在下方居中分行。字段按场合增减 |
| 目录（沿用原版式） | 顶部 `#245A8C` 栏左侧白字“目录”；下方用 `#1F4E79` 大号编号、黑色粗体章节名与范围说明组成列表，右侧列起始页码，条目间以 `#C9D9E8` 细线分隔 |
| 章节首页（沿用原版式） | 延续封面白底、整宽 `#245A8C` 色带与两段短蓝线，色带中居中放章节编号与名称；副标题仅在补充本节范围时保留 |
| 科学插画配解释 | 一侧放白底科学插画，另一侧用黑色粗体小标题引出完整长句，条目间可用 `#C9D9E8` 细线分隔 |
| 场景与双栏卡片对比 | 两张并列卡片（如“已有资料与研究条件”对“需要解决”），按内容量分配左右宽度，可一侧放短文配图、另一侧用细线分隔多组长句 |
| 科学问题与对照表 | 上部放“核心问题”条（左侧 `#245A8C` 标签块 + 右侧白框长句），下部用全宽三列表格对应难点、方法能力与验证方式 |
| 研究框架 / 技术路线 | 用卡片式节点或 `#EFF4F9` 节点展示输入、核心研究内容与独立验证，以 `#1F4E79` 箭头和短标签标出数据流与反馈关系；节点数量和结构由实际研究决定 |
| 公式与变量定义 | 上方按需配 `#EFF4F9` 核心设定条，居中展示主要公式，下方用全宽表格给出符号、含义及单位或约束条件 |
| 图表比较与主要进展 | 双栏卡片或并排图区：一侧展示原生柱状图/折线图或大号核心指标，另一侧放趋势图表、机制路径图及完整长句解读 |
| 原文图表与按需脚注 | 宽图区展示论文原图或原表并可配局部放大图，图下保留坐标、单位与条件说明；引用他人工作时在页底左下角添加一行轻量文献脚注 |
| 讨论与研究局限 | 用双卡片对比“研究发现与贡献”和“适用条件与待验证问题”，直接写清边界与后续验证点 |
| 合作任务与资源汇总 | 上方用“所需人员 / 研究目标”或“合作目标”键值信息表，下方接单张任务表或左右并列的人员、数据/实验双表；不强制两表行数一致 |
| 研究计划 | 全宽时间表配 `#245A8C` 表头与进度条，明确阶段内容、月份范围与阶段交付 |
| 结束页（沿用原版式） | 延续封面整宽 `#245A8C` 色带与短线，居中放“感谢聆听”，下方按场合保留姓名、单位或联系方式 |

## 原文图表、插画与按需脚注

展示已有论文或工作成果时，优先使用原图、原表或清晰截图，保留原始比例、图内字体、坐标、单位和图例，不为套用模板配色而重绘。原图太小或较密时，先裁切、放大或就近加可编辑中文标注；确实缺少清晰原素材、需要教学拆解或重新组织对比时再重绘，并在备课资料记明依据。

需要自制科学插画解释背景或对象时，采用白底、清晰轮廓和蓝灰为主的低饱和配色（可配少量淡紫或青色区分对象），避免在图内堆砌大段文字，术语和变量尽量用外部可编辑文本框标注。

仅在必要时（如页面展示了他人论文原图、原表、实验数据或核心方法观点）在左下角加文献脚注，格式采用：`作者／机构，论文简称，正式期刊／会议或资料类型及年份`（预印本或内部资料按实际类型标明）。页面展示本人工作、整体背景、研究框架或合作安排时，不加文献脚注。

PPTX 示例中的页面内容、演讲者备注和引用只服务于该论文组会演示本身；新建或修改正式汇报时，应依据实际内容和听众重新组织章节与版式。保存后在可用工具中查看页面文字、布局与字体显示，修改溢出的文本框或遮挡后交付。

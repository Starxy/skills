# 实验与进展

## 实验记录与实验报告

实验记录保留便于复现和定位问题的过程信息，包括必要的运行标识、配置、变更和异常。实验报告围绕所回答的问题整理这些记录，突出比较条件、结果及解释。只有影响理解或复现的过程才进入报告主线。

按材料可得性保留：任务与数据范围、基线、关键配置、指标定义、相关结果，以及必要的波动或重复信息。缺少的项目在影响判断时指出，不因填写格式而造出数值。

让检查对应具体结论。处理了多少输入、生成了多少输出说明执行规模；输出是否正确、方法是否改善目标任务需要相应评估。抽查结果按抽查范围陈述，不能仅凭流程完成、字段齐全或多次检查就宣布方法有效、结果稳定。

结果和解释分开写。失败实验、无明显差异和无法运行都可以提供诊断信息；其中哪个改变了判断，就说明哪个。保持原始运行记录完整，报告可合并重复展示。

## 预实验与方法迭代

先说明本轮要判断什么，再报告观察和下一步。小规模结果可以支持“值得扩大验证”或“应先调整某个环节”；结论的范围依据样本与设计确定。无需等所有消融和外部验证齐备后才允许汇报。

对随机性较大、差异很小或实现状态不明的结果，选择能解决当前歧义的复核。结果方向清楚且足以决定下一步时，不自动追加一套投稿实验。

## 处理负结果与权衡

| 观察到的情况 | 报告重点 | 研究决定 |
| --- | --- | --- |
| 目标指标改善，另一相关指标变差 | 同时交代收益、代价和比较条件 | 看是否满足实际需求；有依据时讨论权衡 |
| 未观察到预期提升 | 说明当前数据和设置下的差异及不确定性 | 判断应查实现、修改思路，还是放弃这项改动 |
| 结果推翻原先解释 | 明确哪项解释失去支持 | 撤回或调整该解释，保留仍成立的发现 |
| 效果只出现在部分条件 | 写清条件及其选择方式 | 若为事后发现，将其作为待验证线索 |
| 运行失败或数据处理出错 | 写明已定位的问题与受影响的结果 | 修正后重做必要部分；暂不据此评价科学假设 |

区分“尚未测量”“未检测到差异”和“证据支持没有实际重要的差异”。无统计显著性本身不能证明等效；预算下降伴随效果下降也不自动等于值得采用，需联系实际目标判断。

只陈述有依据的原因。原因未知时，可以提出少量可检验解释，标明下一项实验怎样区分它们。避免用“具有局限”“可能由多种因素造成”替代具体分析。

## 组会、周报与阶段汇报

让听众知道研究判断发生了什么变化，以及现在需要决定什么。可按以下顺序组织，篇幅很短时合并为一段：

1. 本阶段最重要的发现或判断。
2. 支持它的关键结果与已完成工作。
3. 尚未解决、会影响下一步的具体问题。
4. 下一步最值得做的工作，以及确实需要的支持或决定。

保留有信息量的失败、转向和进度偏差。投入了多少工作可以作为背景；汇报价值来自问题变得更清楚、排除了一条路径、定位了瓶颈或获得了可用结果。只有材料支持这些变化时才这样概括。

“目前只完成初步探索”可改为具体完成项及其用途。待完成工作放在计划中，不反复作为自我评价。需要导师决策时明确选项与理由，避免列一长串开放问题。

## 中期、里程碑与项目汇报

对照约定目标交代已经完成的产出、主要证据、实质偏差及调整计划。保持团队实际承诺可追踪，区别“已完成”“进行中”和“拟开展”。范围调整有合理依据时直说理由，不把全部偏差描述成失败，也不把未完成项改写成完成。

对于面向外部的成果汇报，可优先展示成熟结果及价值；会影响对成果判断的条件和未完成事项仍要在相关位置明确。对于内部诊断，优先保留能帮助团队改变方案的信息。

## 幻灯片表达

每页围绕一个结果或待讨论的判断，标题写出这页要传达的信息。用最相关的图、表或短句支持它；配置细节可放备注或备用页。把失败原因、取舍和下一步写成具体内容，不为页数额外增加“创新性不足”“全面性有待提升”等空页。

# 长文覆盖检查与续译

将工作状态与译文一起保存，不能只依靠聊天记忆。使用适合文档的简单清单或表格，不要求特定应用或模式。清单应包含：
- 来源标识、版本和文件哈希；用户要求的范围及输出格式。
- 按顺序排列的原文块 ID 和位置、所属章节或文件、类型（正文、图题、表格、注释、公式等）、输出位置，以及状态：待处理、已翻译、已复核，或不可用及其原因。
- 共用术语表、原版式的关键位置及必要的 CJK 调整、影响文风或版式的决定、受保护内容、尚待解决的原文疑问，以及未翻译的例外内容。

独立于译文建立原文清单。对于大型表格或附录，跟踪粒度必须足以发现缺失的行或段落，不能把整章笼统地视作一个已完成的内容块。受保护的公式和代码应计为已核对的内容，而非已翻译的正文。只统计输出块的数量，无法发现原文块被遗漏。

按语义连贯的章节并结合相邻上下文翻译，不要任意按字符数切块。保存每个已完成单元并更新状态；合并时协调共用术语与衔接。可以并行工作时，划分互不重叠的内容块或文件归属，使用同一术语表与版本；检查合并结果是否有重复或遗漏。

收到“继续”时，先读取现有清单、术语表、成品及上一节结尾。续译用户要求的下一个待处理单元，保留已接受的措辞与版式。不要悄悄重译已完成章节。如果来源哈希或版本发生变化，先确定受影响的内容块并明确核对处理，再复用内容；绝不能混用版本来填补缺失。

只有完成有序覆盖核对、跨章节术语和引用复核，以及格式质量检查后，才能结束。如果中断，保存准确停止位置、剩余内容块和有用文件。将当前交付物标为部分完成，并说明下一步范围；达到 token 或输出限制不能证明全文已经译完。

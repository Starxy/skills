# 仅有 PDF 时的版式重建

未提供 HTML 或 TeX 时，使用用户提供的 PDF。仅有英文 PDF 的全文翻译，默认路线是识别原论文版式、结构和内容，重建中文 TeX，再编译为中文 PDF，并交付可重新构建的源码工程。用户未要求 HTML 时，不主动将 PDF 转成 HTML 翻译，也不以 HTML 或其他文本格式代替所需中文 PDF。

不要把未经请求的源文件搜索设为前置条件。如果用户要求获取结构化源文件，须保持同一版本；否则在本地识别 PDF 的实际页面。

## 先识别原论文的版式、结构和内容

渲染并**实际查看页面**，结合页面尺寸、文字坐标和字体信息，确定要在 TeX 中重建的特征：

- **页面版式：**纸张尺寸、版心和页边距，通栏标题或摘要与单栏、双栏正文的切换，栏宽与栏距，页眉页脚、页码，正文与标题的字体、字号及间距。
- **文档结构：**标题、作者及单位、摘要、关键词，各级章节、附录、参考文献，列表、脚注，以及实际存在的定理、证明、算法或框注；核对各对象的编号和交叉引用关系。
- **内容与阅读顺序：**正文段落、跨页或跨栏续文，行内与展示公式，表格行列、表头和注释，图片、子图及图注；区分页面附属元素与正文，保留作者注释。

在现有翻译清单中记录原文页码和区域位置，版式选择写入工程的体例或构建说明。PDF 书签和元数据可辅助识别，结构以原页实际印刷内容为准。只有 PDF 时，通常不能确认原作者使用的确切文档类、宏包或宏定义；将依据页面选用的 TeX 设置标作重建选择，不声称恢复了原始源码。检查每一种不同版式和每一处存疑区域；说明哪些页面尚未检查。

结合可用的文本提取与视觉检查。扫描页或纯图像页需要可靠的本地 OCR，或对照像素核验的目视转录，也可二者结合；提取不到文本不代表该页为空白。核验负号、上下标、符号及表格行列关系。对于无法辨读的区域，明确指出页码、位置及受影响内容，翻译其余可读部分，仅在必要时索要更清晰的来源。绝不能猜测缺失的正文或公式。

## 按识别结果重建中文 TeX

依据识别到的版式选择能够表达原论文布局的 TeX 文档类、分栏和样式设置，直接建立中文工程。将标题、摘要、章节、公式、图表、脚注和参考文献映射到相应 TeX 结构；保留原纸张、版心、阅读顺序、标题层级，以及图表与图注的对应关系。不要把 OCR 文本直接灌进通用单栏模板，也不要仅为方便就套用通用 `ctexart` 或 geometry 预设。按[中文阅读排版](chinese-typography.md) 接入中文字体、字号和实际行距，以可读字号允许重新分页。

先按原文阅读顺序重建段落，再设置缩进和间距。只有原文确认属于同一段时，才能合并被分页或分栏拆开的续文；保留真正的段落分界、列表、标题，以及公式与周围正文的联系。

逐个对照原页重建公式、表格和编号关系。已编号公式保留原号，必要时使用显式 `\tag{原号}`；未编号公式保持无编号。按原文实际关系建立章节、定理、图表等计数器和引用，避免重新排版后号码变化。重建标签可以另行命名，但不能冒充作者原始标签。

原图优先提取完整图形区域并作为 TeX 资产使用，保留组成该图的位图、矢量、叠加文字、箭头、标签和全部子图；对象提取不完整时，改用整图裁剪或足够清晰的渲染图。图注单独翻译并与图片关联。无法准确重建为可编辑内容的局部公式，可保留忠实裁剪并说明局限；不能以整页截图替代应译写的中文正文。

## 编译并检查中文 PDF

直接使用当前可运行且支持中文的 TeX 环境，通常选 XeLaTeX 或 LuaLaTeX；按 [TeX 工作流程的编译与交付要求](tex.md#编译并验证实际-pdf) 编译重建工程。若缺少引擎、字体或必要宏包，继续交付已完成的中文 TeX 与所需资产，说明具体缺项及中文 PDF 尚未完成。

对比原文与编译输出的实际页面图像，检查覆盖范围、阅读顺序、分栏切换、公式与编号、图表、脚注、字形、裁切和位置。内容完整与中文可读性优先于精确像素位置和页数；说明明显的版式变化与未验证区域。如果渲染或构建受阻，应恰当标注源文件或草稿，不能声称已得到验证通过的 PDF。

除外观外，还要检查重建中文正文能否提取和搜索。区分有意保留的图像或公式裁剪与意外变成纯图像、或缺少字符映射的正文文本层；制作可编辑文本重建版本时，应修复后者。

用户要求对照 PDF 时，遵循[双语对照版式](bilingual.md)，按内容单元对齐，而不是按页码配对。这种按需重新设计不改变纯中文版本默认保留原版式的原则。

# 中文阅读排版

从 TeX 或仅有的 PDF 制作中文 PDF，以及调整翻译后 HTML 的排版时，使用这些建议。它们指导字体、强调方式和阅读密度，不规定文档类、纸张大小、栏数或页面布局。遵循用户选择的风格与阅读条件。以下范围是实用起点，而非强制出版标准。

## 复用已确认的样式

优先顺序为用户明确指定的样式、当前译稿已确认的体例、按阅读条件选择下文起始设置。已有确认值可以超出下文的建议范围。

用户指定已有 PDF 的观感时，先从成品核对正文、各级标题、图注和脚注实际使用的字族、字重、字号，连续普通文本行的基线距离，以及标题前后留白；有对应源码时，一并查明字体映射和行距设置。体例说明与成品不符时，修正当前工程的记录，按成品确定样式。成品不可访问时，说明哪些值尚不能核对。

比较 PDF 时采用同一物理比例或相同渲染分辨率；不同纸张在“适合窗口”下显示的大小不能直接用于判断字号。复用字体与间距时，保留目标论文的纸张、版心、分栏和内容结构，除非用户也要求改变这些项目。参考成品的具体取值用于用户指定的范围。

## 选择协调的字体组合

没有上述样式约定时，中文正文默认使用 Fandol 宋体，西文与数学沿用原论文的配置：

| 内容 | 学术阅读默认设置 |
| --- | --- |
| 中文正文 | FandolSong-Regular，常规字重 |
| 中文标题 | 沿用原稿的字体层级：衬线标题使用宋体，无衬线标题使用黑体；需要粗体时分别使用 FandolSong-Bold、FandolHei-Bold |
| 中文正文强调 | 优先使用正文字族的真实粗体；默认对应 FandolSong-Bold，具体语义见下节 |
| 西文正文 | 保留原字族及其常规、粗体、斜体字面，例如原稿采用的 Latin Modern Roman 或 Palladio |
| 数学 | 保留原有数学字体及宏包配置，维持变量、运算符和常量的惯例 |
| 代码、命令、路径 | 保留原有等宽字族；需要替代时可用 JetBrains Mono 或 Noto Sans Mono |
| 较小的中文图题和表注 | 保留原稿的字体层级；未单独约定时随正文使用宋体，以实际可读性为准 |

需要替代字体或用户另有选择时，可使用 Noto Serif SC 或思源宋体的简体中文字形版本；核对字体实际选用的地域字形。持续屏幕阅读且需要无衬线风格时，可选思源黑体简体或 Noto Sans SC，并保留原稿的西文与数学配置。避免在同一正文段落内频繁切换字族。

使用真实字面和字重，不要模拟加粗或把中文机械倾斜。Fandol 宋体的常规与粗体分别映射到 `FandolSong-Regular.otf` 与 `FandolSong-Bold.otf`。所选字体不可用或缺字时，采用合适的可用替代字体，并说明替换情况。检查渲染器实际选用的字体，包括回退字体；`\bfseries` 表示切换字重，不能据此把标题记作黑体。对于可重新构建的项目，随附允许再分发的本地字体及其许可证，或明确列出确切的字体依赖。若为文档制作了字体子集，须说明新增字符可能需要重新生成子集或使用完整字体。

## 按语义映射强调方式

- **常规／正体：**使用常规正文字面。
- **粗体：**使用正文字族的真实粗体，保持同一字族。
- **语义性斜体：**中文短语优先用正文字族加粗表达强调；用户或已确认体例采用楷体时，使用直立楷体。长段落应保持易读的正文字体，不要通篇使用楷体。
- **粗斜体：**中文使用真实粗体；已有体例采用加粗楷体且有对应字面时可沿用，不机械地叠加倾斜。
- **学科惯例中的斜体：**变量、基因符号、生物学名及其他科学记号应保留规定的西文或数学形式。英文片段是斜体，不意味着其中文译文就必须用楷体。期刊名、书名及拉丁术语应遵循原文学科与引文惯例。
- **无衬线、等宽、小型大写：**使用相应字族或文本角色；已有的西文小型大写应保留，不要凭空创造中文对应形式。

在中西文混合片段中分别映射中文和西文字体。CJK 强调字体不能替换西文科学斜体或数学字形。

## 按栏宽设置 PDF 字号、行距与段落

保留目标论文的栏数和版心，在没有已确认样式时按现有栏宽选择以下起点。数值使用 TeX pt；实际行距指连续普通正文行的基线距离，不含公式、标题或段间的额外留白。

| 正文版式 | 中文正文字号 | 实际行距 | 普通段落额外间距 |
| --- | --- | --- | --- |
| 双栏 | 10 pt | 15.6 pt | 0–2 pt |
| 较窄单栏 | 10.5 pt | 16.4 pt | 2–3 pt |
| 较宽单栏，或需要较大字形 | 11 pt | 17.6 pt | 2–3 pt |

这些组合的实际行距约为字号的 1.56–1.60 倍。选择时同时考虑每行宽度和字数：例如约 80 mm 的双栏栏宽、120 mm 的单栏版心和 150 mm 的单栏版心可分别从上表对应行开始，但不据此改动原论文的页边距或设定固定宽度门槛。阅读条件或已确认成品不同，可以调整；不要把同一组数值套到所有论文。

普通中文正文首行缩进两个汉字，段间距单独设置为表中的额外留白。标题、列表、图题以及公式后接续的句子，应按其作用分别处理，不要给每个内容块都加缩进。正文行距保持均匀，避免长 URL 或不可断开的字符串导致字间距被过度拉伸。

图题、脚注、表格和标题保留原有大小层级与前后留白。需要重新设定时，图题／表注可从正文字号的约 80%–90%、脚注从约 85%–95% 开始，实际行距约为各自字号的 1.4–1.6 倍；标题和短标签可从约 1.25–1.45 倍开始。分别检查其可读性，不把正文行距直接施加到所有环境。

检查实际视觉大小：相同标称字号下，不同字体的观感不同；屏幕上的衬线细节可能需要采用范围内偏大的字号。为上下标及行内、独立公式留出空间，避免碰撞。保持图题和脚注可读，不要仅为恢复原页数而缩小它们。

### TeX 的行距输入值与实际结果

先读取文档类、CTeX、setspace 及手工字号设置中已有的倍率。`\fontsize{字号}{行距输入值}\selectfont` 的第二项还会受到当前 `\baselinestretch` 影响；`\linespread{1.5}` 或 `\setstretch{1.5}` 也不表示实际行距就是字号的 1.5 倍。选择一种明确的行距调节途径，避免重复施加倍率。

例如，`\fontsize{10.5pt}{15.2pt}` 在 `\baselinestretch=1.3` 时，实际基线间距为 15.2 × 1.3 = 19.76 pt；设为 `\linespread{1}` 并重新选定字体后，才是 15.2 pt。复用前者的观感时，应保留 10.5 pt 字号和 19.76 pt 实际行距这两个结果。此例用于说明倍率计算，不作为所有论文的默认配置。

分别核对正文、图注、脚注和多行标题；`\normalsize`、`\small` 等字号命令及环境切换可能重新设置行距。在标题、摘要或局部字号环境结束后，确认恢复的正文仍使用选定的字号与行距。可在临时构建副本中输出当前字号、`\baselinestretch` 和 `\baselineskip`，再用 PDF 连续普通文本行的坐标确认，比较前统一 PDF 坐标与 TeX pt 的单位。高公式、段落切换或局部留白造成的额外距离应分别识别。

## HTML 屏幕阅读

保留网页原有宽度与响应式布局。电脑／平板正文可从 16–18 px、`line-height` 1.65–1.85 开始，小屏幕可从 15–17 px、行高 1.6–1.8 开始。这些 CSS 建议不直接套用到固定页面 PDF；PDF 的字号与行距也不直接覆盖 HTML 的屏幕设置。

## 检查渲染结果

以适合阅读的比例检查正文段落、标题、强调文字、密集图题、表格单元格、数学片段，以及跨页和跨栏处。确认所选字体及字重确实生效，中文强调保持直立，西文及科学斜体得到保留。调整字号或间距后，修复重叠、文字裁切、过宽公式、拥挤的图内标签及不合理的跨页框体；保留内容和图题对应关系，允许页数增加。文本提取与编译成功只能补充视觉检查，不能取代它。

将采用的实际字族、字重、字号、行距、标题留白及对应源码位置写入交付工程已有的体例或构建说明；采用指定成品时，记明参考文件和代表页。TeX 同时记录行距输入值、有效倍率与实际基线距离，正文及各局部设置分别记录，避免后续只复制输入值而改变阅读密度。

## 字体来源与适用边界

官方字体项目：[Fandol](https://ctan.org/pkg/fandol)、[思源宋体](https://github.com/adobe-fonts/source-han-serif)、[Noto Serif SC](https://fonts.google.com/noto/specimen/Noto+Serif+SC)、[思源黑体](https://github.com/adobe-fonts/source-han-sans)、[Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)、[JetBrains Mono](https://www.jetbrains.com/lp/mono/) 和 [Noto Sans Mono](https://fonts.google.com/noto/specimen/Noto+Sans+Mono)。

[W3C《中文排版需求》](https://www.w3.org/TR/clreq/) 提供更广泛的中文排版背景。此处数值范围是为本技能提供的阅读建议，并非归属于 W3C 的规范要求。这些链接仅用于标识资源，不要求每次翻译都下载字体。

# 按卡点展开，不把每篇论文做成同一张表

## 最小演练

选一个能体现中心改变的例子，而非一个避开困难的特例。说明初始已知条件，逐步展示对象如何改变，再映射到论文的一般描述。教学数字必须可算且显式标注；论文没有给出的经验结果不能补成“示例结果”。

- 算法：不仅列 encoder → memory → decoder，还要说当前输入、读出的内容、更新后的状态，以及输出依赖什么。训练可见的标签/未来观测不应偷偷进入部署输入；训练损失与部署决策也不是同一个步骤。
- 理论：先准确陈述结论和假设，再给“由 A 经关键引理 B 得 C”的最短链。解释 B 为什么适用、哪个假设在此使用。若去掉假设，只能说保证不再由该证明成立，除非确有反例，不能断言结论必错。
- 实验：用一个样本/处理组走过干预、测量、比较与推断。分清实验单位与测量次数，不把重复测量当独立样本。
- 定性：若有原始材料，示范材料片段如何进入编码、如何支持主题，并保留不吻合的材料；若没有原始材料，说明只能重建作者报告的分析路径，不能编造受访者引文。
- 综述：用一个边界案例走过分类标准或论据到结论的桥，指出概念交叠、材料覆盖和作者立场。不硬造新实验或计算流程。

## 前置桥与形式化

先判断缺的是对象、操作还是关系。以“注意力”为例，定义加权平均可能解决词义，但未必解释权重从哪里来；此时应演练查询、匹配、归一化、聚合，而不是再换一种比喻。只展开论文实际采用的形式，不拿熟悉的标准版本替代。

公式应连接具体动作：这一项惩罚什么，分母在哪些对象上归一化，约束排除了哪些解。中间一步恰是核心贡献时必须解释；机械代数可以省略。说明形状、单位、梯度或信息可见性，只在它们影响当前理解时加入。

## 图与证据

把关系外化是为了减少读者脑内拼装负担。先说图回答的问题，再说读法及结论；每根箭头有明确语义，区分观测到的关系、设计数据流和解释性推断。不能读取实际图时，不以“示意图”偷偷还原其结果。

说明一个自然替代可以暴露设计意图，但必须标明证据类型：论文做过的消融可报告观察；由公式推得的差异可演算；没有验证的性能差异只能是待检验解释。不给未知替代方案虚构排名。

## 可选理解检验

优先问“换一个输入/去掉一个假设后，哪一步会变，为什么”，而非“有几个模块”。答案应可由当前讲解和原文推出。若问题无法回答，先检查正文是否缺桥；这不是自动给用户打分的测验系统。

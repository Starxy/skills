# 行为评测：是否支持读者形成可操作的理解

这套自含案例检查解释行为，不测实际学习增益。`npm run check` 与 `quick_validate.py` 只验证结构；不要把通过格式检查、命中某些标题或关键词当教学效果。无需模型 API、额外依赖或自动评分引擎。

## 运行方式

1. 在隔离会话中加载当前 `SKILL.md` 和它按需引用的材料，给予 [cases.md](cases.md) 中一个案例的用户请求与原始材料。不要把下方评审标准或参考答案交给被测模型。
2. 保存请求、原始回答、模型/环境、技能提交版本与日期。案例 D 执行两轮；I、J 按给定顺序逐轮提供材料或追问；K 仅先给目录，再按被测模型的读取请求返回原始区间并保存读取记录。除明确给定的上下文外，案例间不要共享答案。
3. 评审者按实际输出判断；接受不同但正确的解释、组织形式和合理的替代答案。每项给具体回答片段或遗漏位置作为依据，不按措辞匹配。
4. 修改后重跑受影响案例。可在同等材料与篇幅下比较旧版，但先定义目标，避免把更长当更好。真实读者学习效果需另做控制背景与阅读时间的理解/迁移测试，模型自评不构成该证据。

## 共用评分标准

每项 0–2 分：0=错误或缺失；1=部分做到但读者仍需跨越关键缺口；2=足以支持当前请求。只评分适用项，报告分项与理由，不用总分掩盖事实错误。

- **问题与前置桥**：具体指出对象、约束和卡点；没有不必要的领域课程。
- **机制/论证可操作性**：读者可沿回答得到中间状态与结果，或复原关键推理；不是模块名堆砌。
- **条件与设计理由**：信息可见性、假设或样本范围正确；自然替代和已验证结果分清。
- **证据解释**：把问题、对照、结果及推断边界连起来；主张可定位，反证不隐去。
- **适配与负担**：尊重用户语言、篇幅、深度与局部范围；解释连续，不重复两份长摘要。

硬失败：编造缺失实验/公式/引文；将教学数值冒充实测；混用版本；把训练未来信息作为部署输入；把上界说成实际概率；不可比结果直接宣称优越；缺关键材料却宣布完整精读。这些不能靠其他维度高分抵消。

## 各案例判断依据（仅评审者）

| 案例 | 应可观察的理解支持 | 典型失败 |
| --- | --- | --- |
| A | z=1；a=-1 预测 -1，距目标平方为 25；a=+1 预测 3，平方为 1，因此选 +1。训练中 o_next 是监督目标，选择动作时不可见，执行后才获得新观测。70% 对 50% 支持当前比较，不证明所有组件独立有效或统计显著。 | 只说“编码—预测—决策”；提前使用真实未来值；凭成功率认定新颖性或因果归因到编码器。 |
| B | 解释均值除以 n 导致方差除以 n²，独立性消去交叉协方差；接切比雪夫得到界。n=4 的 1/4 为上界。依赖改变时原证明不能照搬。 | 只抄定理；认为均值一定更接近 μ；把相关性一律等同定理结论必错。 |
| C | 走通随机分组、处理、三次测量取均值及组间比较。每组 n=10，不是 30；观察差 3 cm，不虚构检验。单地点/剂量/品种/时间与叶黄现象限制外推。 | 强套训练/推理；宣称所有植物更健康或增长统计显著；把株高等同长期存活。 |
| D | 解释候选动作尚未执行，没有对应真实下一观测；给一处最小桥即可。第二轮仅改指定段落并消除重复。 | 重讲整篇；重新问已明确背景；整合时追加第二份独立注释或改动其他结论。 |
| E | 明确无法完成核心更新规则与完整精读，点名 Appendix A；如给受限概览须标范围，不自行补算法。 | 将“校正记忆”猜成某常见更新公式；以摘要稿冒充完整结果。 |
| F | 保持 v1 的 A=80/10 次、B=85/100 次；口径不完全可比。v2 只能作为明确分开的差异，不能支持 v1 结论。 | 报 A=90；说 v1 中 B 公平胜出，或暗示 v1 已有等预算实验。 |
| G | 由同一句两部分到两种编码，再到并存主题；说明可以双重归类。负面案例限制普遍性，建议是规范性主张，6 位自愿样本无对照不能证明远程工作更好。 | 虚构更多访谈、比例或编码流程；硬套张量；把作者解释当参与者逐字原话。 |
| H | 100 汉字以内，标仅摘要，交代缺失观测预测与方法主意、实验/机制细节未知；不检索。 | 因全文门槛拒绝所有摘要；强写固定长模板；补具体算法、数字或不存在的证据。 |

## 新增连续阅读案例的判断依据（仅评审者）

这些案例是可运行的测试设计，不是已通过的结果。不要把本节发给被测模型，也不要让后续轮次提前进入其上下文。

| 案例 | 应可观察的理解支持 | 典型失败 |
| --- | --- | --- |
| I | 前两轮只简短确认接收范围，没有提前完成全篇解读。第三轮将三批作为同版本整体：稳定行仍支持当前比较，突变行原口径不一致，校正后 6 对 5 不能支持平均器更优。教学序列中平均器预测 5、平方误差 25，基线预测 10、误差 0；用它解释平滑与滞后的取舍，明确非 Table 1 实验样本。定位 §2、§3 与 §A.1–A.3，回修引言主张而不是把矛盾并列保留。 | 提前交全文稿；仅合并局部摘要；保留两个条件都优于的结论；把同版本附录更正误判成换版本；发明自适应算法、显著性或训练参数。 |
| J | 第一轮分清同一参数集合、不同条件分布角色与同一输出空间，不推断数值相等。第二轮从定义转向信息时间线：动作尚未执行，两条候选分支各自真实下一观测都不可得；模型预测不等于已观测事实。第三轮把 theta、z_t、o_(t+1) 和执行前后两头的使用合成一段，保持部署参数固定。 | 第二轮重复定义或泛讲概率；用某条真实执行后的观测替其他未执行候选分支；因为同写 p_theta 就合并两种角色；把输入状态更新说成权重更新；编造闭式分布或数值。 |
| K | 完成前取得 R1–R5 的实质内容（顺序不限），没有把推荐区间当全文。教学输入先留 [-1,2]，最终选 2，距离 6；全候选最优为 9，距离 1。结合 §3–§5 解释高于随机、低于未筛选的准确率及筛选丢失目标近邻的原因；不把缩小距离比较集合直接等同整体速度更快。 | 仅读 R1/R3 就宣布完整；没有 §2 仍猜机制；漏掉消融与限制；用 60% 对 35% 宣称优于未筛选；虚构实际加速。 |

### 记录与比较

- I 可另开一个会话，将三批原文一次性提供并请求同样解读。比较两种输入方式的机制、关键条件与证据判断，不要求措辞、篇幅或阅读顺序相同。
- J 保留每轮原始回答，检查解释是否随真实卡点从定义转到过程，再按用户要求整合，而非单独评价最终一段。
- K 的阅读记录用于确认材料实际取得，最终回答仍须解释消融如何改变结论；读完文件本身不算通过。
- 旧案例 A–H 继续独立运行，防止新分批协议迫使短摘要或局部问题等待全文。

建议在记录中单列未运行项；所有自含案例通过也不能声称对真实论文或真实读者普遍有效。

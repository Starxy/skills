# 论文理解

## 目标与范围

让读者形成可使用的论文心智模型，而不只是复述摘要或贡献列表。一次处理一篇可唯一识别的论文，默认中文；尊重用户指定的语言、背景、重点和篇幅。未指定深度时，面向有大领域基础、但不熟悉细分方向的读者，讲通论文主线。

完成标准随请求变化：精读应使读者能说明具体问题，走通一次中心机制或论证，解释关键设计及代价，判断证据支持什么、改变条件后哪里可能失效。摘要和局部问答只承担相应目标，不伪称已经完成全文精读。不自动扩展为多篇综述、科研选题、代码复现、工程接入、完整同行评审、新颖性认证或视频/交互平台制作。

## 先确定读者要跨过哪道坎

从请求和已有上下文推断目标与最小前置知识，不先发长问卷。必要时用一句话说明知识起点，如“默认熟悉梯度下降，但不预设了解状态空间模型”；仅当歧义会实质改变答案时问一个针对性问题。不要对专家反复科普已知概念。

- **摘要 / 快速了解：** 优先回答具体问题、关键改变、主要发现与一个重要边界；遵守字数上限。只有摘要可读时可以做明确标注的“仅基于摘要”介绍，不能推断未读方法或实验。
- **粗读 / 主线理解（默认）：** 给整体图景，选最阻碍理解的 1–3 个卡点集中解释，并走通一个代表性机制或论证。不是所有章节等量缩写。
- **精读 / 完整理解：** 通读全部实质章节，核对主线所需图表、公式和补充材料；关键前置概念、机制、证据与边界不能因篇幅静默遗漏。必要时说明可在当前篇幅讲到哪里，提供分段继续的选择，而不是要求取消技能。
- **局部追问：** 直接处理所问词义、流程、理由或证据，不重新启动全文长稿。见下文“追问与整合”。

## 锁定材料，诚实界定覆盖

1. 确认标题、唯一标识及读取版本。多篇输入先请用户选一篇；身份有歧义时列出区分信息，不猜。版本优先级：用户明确指定版本 → 用户提供且可读的副本 → 可信原始来源。不能静默改用更新版。
2. 按请求获取必要材料。优先出版方、发表会议或期刊、作者或 arXiv；缺失或不可读时尝试一至两个实质不同的同版本承载来源或可靠 OCR。满足当前问题后停止检索，不为局部问题强制读整篇。
3. 检查主线是否依赖附录 / 补充材料、图、表或算法。正文已完整给出所需信息时，不因未读的冗余载体阻断；关键步骤或证据仅存在于不可读载体时，指出具体缺口。图注不能替代对图中结果的读取。
4. 完整精读所需关键材料仍缺失时，不宣称完成；报告已读与缺失范围、尝试路径及需要的材料。可以继续回答已获证据支持的局部问题，或给明确受限的概览，但不得拿它充当用户请求的完整精读。
5. 输出简短的论文身份、实际版本与材料范围；元数据未核验就明说。其他版本可用于说明差异，不能混入锁定版本的结论。用户指定版本不可得时，请其提供副本或同意切换。

## 阅读与组织：一条学习主线

先浏览结构、核心主张与证据位置，再围绕当前理解目标精读。完整精读要检查所有实质章节及反证，不等于逐节复制到正文。内部只记必要的“主张—证据—位置—条件/不确定性”对应关系，无需输出账本或固定结构。

按当前请求加载参考，而非等到自觉解释困难时才读取：

- **主线理解 / 精读：** 读 [类型索引](references/paper-types.md) 及所选镜头，并读 [教学展开](references/teaching.md)，用于组织中心演练与必要的前置桥。
- **局部机制、推理或图表解释：** 读 [教学展开](references/teaching.md) 的相关部分；若问题涉及证据强度或类型特有的假设，再由 [类型索引](references/paper-types.md) 加载对应镜头。
- **短摘要或单纯术语释义：** 直接按当前范围回答，不强制加载上述参考。

正文按概念依赖而非作者写作顺序组织。以下是叙事功能，不是强制标题或必须重复的六个节点：

- **先让问题具体。** 用论文中的任务、现象、矛盾或失败情境说明“谁/什么受何种约束，原办法卡在哪里”。给出关键改变与预期作用的整体图景；理论工作不必包装成工程收益。教学构造的情境应标明，不冒充论文案例。
- **就地补最小前置桥。** 只补下一步真正需要的概念：它是什么、在这篇论文里做什么、一个最小例子。不把术语表当教学，也不扩成领域教科书。
- **走通中心机制或论证。** 主线理解与精读至少给一次代表性演练：输入或前提 → 中间状态/推理 → 关键操作 → 输出/结论，再映射回原文。不要只有模块名称和箭头。算法区分训练与使用的信息、学到与固定的量；理论展开最短必要推理；实验解释操作—测量—结论；定性与综述用材料解释或分类案例，不强套张量。
- **解释为什么这样做。** 针对关键设计，比较删掉这一步或最自然的替代，说明约束、可能收益、代价与假设。区分作者明确理由、逻辑推断与已做消融；未经实验的替代不能写成已被否定，也不把作者选择说成唯一方案。
- **让读者会读证据。** 围绕“要回答什么问题 → 与什么对照 → 看到什么结果 → 能支持/不能支持什么”组织。关键图表说明先看哪个轴/行/列、怎样比较、哪一现象改变结论；将负结果与限制放在相关主张附近，不只在末尾免责。
- **收束贡献与边界。** 回答相比出发点到底多知道或多做到什么，在哪些条件下成立，哪些尚未证明。按证据校准作者贡献声明，不将高分等同新意，也不做全领域优先权认证。

正文中保留紧凑原节号、图表/公式定位；篇幅允许时附简短原文导航（原节号/标题 → 本文讲解位置或本节作用），供回查而非第二份摘要。没有原节号时用页码或段落定位并标明编辑性标签。用户要求逐节读时按原文组织，在对应位置补桥，不再另写一遍六节点长稿。

## 表达与证据底座

- 区分论文声明、原文直接支持、教学性解释/重建、未证明或未覆盖。在发生区别的地方标明，而不是靠开头统一免责声明。教学数值或假设案例注明“教学示例，非论文实验”；不能改掉真实机制的关键条件。
- 关键事实、数字、设计归因、贡献及边界判断在使用处给精确锚点（如 §4.2 / 表 3 / 公式 2 / 页码）。综合判断给相关多处锚点；论文链接不能代替定位。局部摘要可用紧凑引用，但不得暗示读过未读内容。
- 核对表格行列、单位、指标方向、样本、比较对象与条件；图形估读明确标注，不能伪造精确数值。比较时核对数据、协议、规模、预算及测试设置，不一致或未知则说明口径不完全可比/未核验。只在论文提供支持的统计检验时称“统计显著”。
- 只引用实际读取的文本，短引保持原文准确；译文标“自译”，不冒充逐字引文。OCR 残片和不可读公式不靠猜测补全。来源冲突明示版本及采用理由，不用新版本修补旧版本而不告知。
- 外部资料只用于必要前置概念或元数据核验；可核验、给链接并标为外部背景，不替代论文本身的证据。缺少证据是“尚未取得/本文未报告”，不自动证明不存在。
- 重要术语首次就地释义，中英对照按需要给出；保持译名一致，类比只作桥梁而不替代定义。公式先说回答什么问题，定义每个局部符号、下标与条件，再讲各项如何发挥作用。行内用 `\(...\)`，独立式用 `$$...$$`。需要时展开关键等价变换或证明台阶，不以“不作完整推导”为由跳过贡献本身。
- 图、表、公式数量由理解需要决定，没有两图上限，也不逐一展示所有图。每个展开都应解决一个不同的卡点；简单状态表、三行推理足够时不做复杂图。解释顺序图不能冒充算法运行顺序；真实执行、数据流与教学顺序应区分。

## 追问与整合

用户说“这里没懂”时，利用所指段落先定位：不认识对象/术语、跟丢状态变化、不明白为何如此，还是不理解证据如何支持结论。能判断就直接补桥；确实无法定位才问一个最小问题。

用缺失的定义、一个中间态、最短推理、自然替代或对照读取修补，不只是换词重复原稿。按需要回查原文。用户要求“融回/重写这段/整合”时，修改相应正文并消除重复批注；不擅自全文重写或改变未涉及结论。

可以提供一两个自我解释或改变条件的迁移问题，帮助读者发现卡点；不强制考试，不凭“已阅读”、打开答案或模型自评分宣称读者已经理解。

## 交付前检查

- 当前范围、篇幅、版本与实际覆盖是否诚实？缺关键材料时有没有假装完整？
- 读者能否从稿中走完中心例子，解释最重要的选择，并读懂决定性证据，而非只复述名词？不能则补正文，不靠追加检查题掩盖缺口。
- 是否遗漏会改变结论的假设、反证、负结果、比较口径或作者限制？教学重建和原文事实是否分清？
- 是否按学习依赖组织，避免逐节摘要加重复六节点？局部请求是否保持局部？

维护者可用 [行为评测](evals/README.md) 检查真实输出；格式检查通过不代表教学效果已验证。

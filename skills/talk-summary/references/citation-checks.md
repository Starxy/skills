# 引用与来源核验

每次成稿后使用。目标是确认“这份来源在该位置是否支持这句话”，包括字面、归属、位置与语义；不把引文存在等同于事实已经得到证明。

## 建立可回查锚点

使用实际材料能够支持的最细定位：

| 来源情况 | 锚点方式 |
| --- | --- |
| 有时间戳的字幕或转写 | 标注包含证据的时间段，如 `（嘉宾 A，00:12:08–00:12:41）`；只有起点就只标起点 |
| 无时间戳的文本文件 | 文件名与实际行号，或稳定的段落编号，如 `（访谈稿，第 18–20 段）` |
| 粘贴的无编号文本 | 按原文自然段建立编号，首次说明“段落号按所提供文本计”；段落过长时附可搜索的短句 |
| 来源只提供章节或页码 | 用实际章节 / 页码，并附可搜索短句定位；不用臆造的秒级时间 |
| 多份材料 | 每个锚点包含来源标识；不同文件的相同时间戳不可混用 |

片段时间沿用来源坐标。原始字幕从 01:10:00 起始就保留该时间；只知道片段内时间则注明“片段内”，不猜测相对于整场的偏移。ASR 时间只精确到字幕段时，按段定位，不根据语速或词数插值。

可点击时间链接仅在媒体地址及跳转格式已确认时使用；否则可读的时间与来源链接已经足够。锚点选能包含支持证据的最小有意义范围，不能给一整小时范围冒充精确定位。

## 直接引文：逐条核对

1. 从最终稿收集每一处作为来源原话呈现的文本，包括引号和引用块中的原话。术语引号和用户提供的待讨论表述按其身份区分。
2. 打开所引原文位置。引文必须是该位置中的连续原文片段；可以选短句，不拼接相距较远的词句形成新金句。
3. 逐字比较。精确检索可以辅助发现错误，比较时只容许空格、换行等排版空白规范化；不能忽略否定词、改写同义词、改数字、补字或改大小写后声称逐字一致。跨字幕条目时只拼接相邻且同一说话人的文本，并保留这些条目的位置。
4. 阅读引文前后文，核对谁在说、是否引用他人、是否是假设或讽刺，以及后文是否立即否定或修正。常见短句在其他位置出现，不足以证明当前归属和锚点正确。
5. 无法核验时修正为可核验原句，或改为有依据的释义并去掉原话标记；证据不足则删除或明确存疑。先前检查通过的引文被改写后，重新核对。

引用 ASR 稿只能保证与该稿一致。没有听取对应音频时不能声称“已核对录音原话”；疑似识别错误会影响意思时优先使用明确标注的释义或报告疑点。若输入是润色稿，明确所引版本，不称其为录音的逐字记录。

跨语言时保留简短原文作为直接引文；附上的中文或其他语言译文标为“译文”或“自译”。译文按语义核验，不要求出现在原文，也不能伪装成逐字引用。普通总结的跨语言转述无需逐句标“译文”。

## 关键主张：检查语义与归属

对核心结论、具体数据、因果关系、方法步骤、建议和综合洞见逐项回查：

- 锚点处是否实际表达了该主张，而不只是提到同一主题？多个独立主张分别附支持位置。
- 名称、数字、单位、时间、版本、分母和比较基线是否一致？参数属于哪个步骤，结论属于哪个设置？
- 说话人是肯定、否定、推测、举例还是转述？一个问题不能当作提问者的立场，主持人的概括不能自动归给嘉宾。
- 来源给出的是相关、解释猜测还是因果证据？保留原来的强度与限定词。
- 跨段归纳是否有各段支持，是否被标明为总结者归纳？说话人冲突、撤回与未决问题是否仍然可见？

资源名称无法唯一识别时保留原称并标出不确定处，不猜网址、论文题目或作者。外部查到的链接须明确只是资源核对；没有读过的资源不能作为当前总结的证据。

## 章节与时间一致性

用户要求保留的章节标题、顺序和时间应与其提供的章节记录逐项对应。起止时间需满足开始早于结束、处于已知材料范围内；只有已知时长才能校验时长上界。跨章节主题的证据分开标注，不能伪造连续区间。

来源章节记录冲突或无法解析时指出问题，保留可确认部分；不能删除约束后宣称校验通过。自行组织的主题可以不同于来源章节，但应作为总结主题呈现。

## 核验结束条件

全部直接引文已经逐字回查；全部关键主张的归属、条件和支持位置已经检查；章节与时间没有已知冲突。核验记录留在工作过程中，不给每条结论添加机械的“已核验”标记。无法确认的项目必须在成稿中修正、降格、标明缺口或移除。

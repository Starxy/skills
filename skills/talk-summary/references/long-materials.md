# 长材料处理

在材料无法一次读取、超出上下文容量或分多批提供时使用。分块解决读取限制，最终取舍仍针对全部已声明范围。

## 分块与覆盖

1. 固定来源与版本，记录总范围以及文件、字幕序号、行号或时间范围。保留可回查的原文；段落编号按该版本建立，不因后续重排而改变。
2. 优先沿自然主题或发言边界分块，为问答、代词指向和中断的论证保留必要前后文。相邻块重叠只用于理解，不能算成两份独立证据。
3. 逐块读取，维护覆盖表：`块 / 来源起止位置 / 已读状态 / 主题 / 待接续内容`。工具返回截断时，补读截断之后的范围，而不是把一次调用当作全文读取完成。
4. 一块读完只记录证据，不提前写最终总结。继续读取，直至输入末尾；若用户正在逐批发送，保留进度并等到声明的最后一批后再生成全篇总结。

覆盖检查依靠来源位置，不依靠块数或输出字数。全文读取可以跨批完成，不要求全部原文同时驻留上下文。

## 可用于全局综合的记录

每块记录足以还原关键论证的内容：

- 主张与对应说话人，是否是引用他人、假设、玩笑、追问或确定立场。
- 关键事实陈述、数字、条件、步骤、证据和反例；保留具体细节，不只存主题标签。
- 新概念与术语别名；同一人物或实体的不同称呼。
- 可引用原文及精确位置，与释义分开保存。
- 本块如何承接、补充、限制、反驳或修正前文；尚未回答的问题。

源材料很长或跨上下文时，将记录保存到任务内的工作文件，并保留原文路径。不能只保留每块的一小段摘要后反复压缩，那会优先丢失条件、少数观点和后文修正。

## 全局综合

读完全部范围后再执行：

1. 按主题合并证据记录，统一可确认的术语与身份，消除重叠块产生的副本。
2. 区分无新增信息的重复与有意义的变化。后文明确修正前文时采用修正后的主张，并在变化本身重要时交代；未明确解决的冲突并列保留。
3. 在整个内容范围内分配预算。反复提到不等于更重要；后半段的一个限制可能比前半段多个例子更值得保留。
4. 抽查主题之间的依赖是否仍可读；技术步骤是否失去前置条件，人物叙事是否失去关键转折，多人问答是否错配问题与回答。
5. 对成稿中的全部直接引文与关键主张回到原始位置核验。中间记录是索引，不代替原文作为最后证据。

## 不完整材料

- 某段无法读取：标出实际缺失范围，收窄相应结论。不能将缺失段落记为“无重要内容”。
- 用户只要求当前片段：就当前范围完成，不等待不存在的后续材料。
- 完整材料尚未提供：可按用户要求交付已读部分总结，明确截止位置；后续全篇版重新全局取舍，不直接拼接阶段总结。
- 读取或工具限制阻止继续：交代已完成范围与缺口，不宣称全篇完成。
